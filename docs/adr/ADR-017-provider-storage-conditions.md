# ADR-017 — Условия хранения ответов провайдеров

**Дата:** 2026-09-19, дополнено 2026-09-25 (Anthropic, T-78)  
**Статус:** Принято  
**Зависимости:** До T-27 и T-28; раздел Anthropic — до T-78

---

## Контекст

Техплан требует проверить условия OpenAI, Perplexity, Google и (с версии 1.7 плана) Anthropic на хранение ответов API и построение агрегатов перед реализацией адаптеров ChatGPT (T-27), Gemini с grounding (T-28) и Claude (T-78). Вопрос: допустимо ли хранить сырые ответы (поле `raw`) 12 месяцев и строить по ним агрегаты?

---

## Решение по провайдерам

### OpenAI (ChatGPT, Responses API)

- Данные API-запросов и ответов **не используются для обучения** моделей по умолчанию (API Usage Policy, Enterprise & API Terms, 2025).
- Хранение ответов на стороне клиента на срок до 12 месяцев **разрешено**.
- Responses API с `web_search_preview` возвращает URL источников из публичного веба — ограничений на хранение URL и цитат нет.
- **Вывод:** сырые ответы хранятся 12 месяцев без ограничений.

### Perplexity

- Данные API не используются для обучения (Developer Terms of Service, 2025).
- Хранение ответов и построение агрегатов **разрешено**.
- **Вывод:** сырые ответы хранятся 12 месяцев без ограничений.

### Google (Gemini API с grounding)

- Gemini API с grounding (`google_search`) возвращает `grounding_chunks` — ссылки на публичные страницы Google Search. Google не запрещает хранить URL и текст ответа.
- Полный `grounding_metadata` (метаданные поиска) технически тоже хранимы, но он не несёт ценности для агрегатов: нужны только `text` и `sources`.
- **Вывод:** хранить `text`, `sources` и `usage` 12 месяцев — разрешено. Поле `raw` (полный ответ API включая `grounding_metadata`) также хранится, но **при нарушении условий провайдера TTL поля `raw` для Gemini сокращается до 30 дней** через отдельную задачу очистки. Агрегаты строятся только из `text` и `sources`.

### Anthropic (Claude, Messages API с инструментом веб-поиска)

- Данные API-запросов и ответов **не используются для обучения** моделей без явного разрешения клиента (Commercial Terms of Service, стандартная политика хранения данных Anthropic, сентябрь 2026): «Retained data is never used for model training without your express permission».
- Claude Haiku 4.5 (модель адаптера, ADR-024) не входит в список Covered Models, для которых Anthropic требует обязательное 30-дневное хранение на своей стороне, — стандартная политика применяется без исключений.
- Результаты инструмента веб-поиска (`web_search_tool_result`, включая `encrypted_content` и `web_search_result_location`) возвращаются в теле ответа API как часть обычного содержимого сообщения; Anthropic не отдельно регламентирует срок хранения самого текста результатов и цитат на стороне клиента — политика хранения на стороне Anthropic не ограничивает то, что мы храним у себя.
- Поле `encrypted_content` внутри `web_search_result` — непрозрачный блок, нужный только для многошаговых диалогов (передать обратно на следующий ход); агрегаты строятся из `text` и `sources` (`citations`), как и для трёх других провайдеров, и не зависят от этого поля.
- **Вывод:** сырые ответы Claude хранятся 12 месяцев без ограничений, тем же порядком, что и для OpenAI, Perplexity и Google.

---

## Итог

Для всех четырёх провайдеров хранение сырых ответов 12 месяцев **допустимо в текущей конфигурации**. Специальной обработки `raw` по типу движка не требуется.

Мониторинг: если условия провайдера изменятся, обновить это ADR и добавить к T-56 (очистка артефактов) TTL-правило для поля `raw` по движку.
