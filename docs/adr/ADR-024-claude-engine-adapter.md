# ADR-024 — Адаптер Claude: четвёртый движок платных профилей

**Статус:** Принято
**Дата:** 2026-09-25
**Контекст:** T-78, зависит от T-07

> **Нумерация:** техплан (версия 1.7, приложение М) называет это решение «ADR-023»
> по собственной внутренней нумерации документа. В репозитории эта позиция —
> ADR-024, потому что план веб-версии 1.2 предполагал «ADR-018 — локали»,
> но ADR-018 в репозитории уже занят («Email-гейт», T-25/T-26) — см. примечание
> в ADR-019. Каждый следующий пункт плана сдвинут на +1: локали → ADR-019,
> без поиска → ADR-020, клиентский слой → ADR-021, поэтому Claude-адаптер —
> ADR-024, а не ADR-023. Решения по аутричу (план: ADR-021/022) резервируют
> ADR-022/023 в репозитории и будут оформлены при реализации соответствующих
> задач (T-70+).

## Контекст

Концепция продукта (версия 1.5, раздел 9.2 пункт 6) добавляет Claude четвёртым
движком оценки видимости — наравне с Perplexity, ChatGPT и Gemini. Причина:
Similarweb фиксирует долю Claude в визитах в AI-ассистенты на уровне ~9% —
заметная доля покупателей задаёт вопросы именно там, и аудит без Claude не
видит эту часть картины.

Meta AI и агент Muse решение прямо исключает из реестра движков — это отдельный
эксперимент фазы 2, не часть T-78.

## Решение

1. **Только платные профили.** Claude опрашивается в `standard` и `extended`;
   `teaser` и профиль аутрича остаются на Perplexity — дороговизна поиска
   Claude ($0,01 за вызов инструмента плюс токены) не оправдана на бесплатном
   прогоне.
2. **Модель — Claude Haiku 4.5** (`claude-haiku-4-5-20251001`), не флагман —
   тот же принцип, что и для ChatGPT (раздел 8.1 техплана): флагман ломает
   потолки стоимости профиля.
3. **Инструмент веб-поиска с `max_uses: 1`.** Без ограничения число поисков за
   вызов определяет сама модель, и цена растёт непредсказуемо. Ограничение
   ставится на уровне запроса (`tools[].max_uses`), а не проверяется постфактум:
   превышение возвращает `max_uses_exceeded` внутри `web_search_tool_result`,
   а не отдельную ошибку HTTP.
4. **Режим без поиска не используется.** Срез «знание без поиска» (ADR-020)
   остаётся на ChatGPT (`standard`) и на ChatGPT с Gemini (`extended`); Claude
   туда не входит ни в одном профиле — второй прогон без инструмента поиска
   для Claude не даёт нового измерения, которого нет у уже участвующих
   движков, и не оправдывает лишний вызов.
5. **Тарификация — по факту, не по предположению.** Стоимость поиска считается
   от `usage.server_tool_use.web_search_requests` в ответе API (0 или 1 —
   `max_uses: 1` это гарантирует), а не от жёстко зашитой единицы: ответ, где
   Claude не искал вовсе, не должен внутри нашей системы стоить как ответ с
   поиском.
6. **Условия хранения ответов Anthropic** — раздел «Anthropic» добавлен в
   ADR-017 (условия хранения ответов провайдеров): вывод по OpenAI/Perplexity/
   Google из ADR-017 распространяется на Anthropic без исключений.

## Причины

- Общий контрактный набор тестов (ADR-008/T-07) — тот же чек-лист, что и для
  трёх существующих адаптеров, без дополнительных тестов под конкретный движок.
- `usage.provider = 'anthropic'`, `id = 'claude'` — тот же паттерн расхождения
  provider/id, что уже есть у ChatGPT (`id: 'chatgpt'`, `usage.provider: 'openai'`).
- Источники цитат берутся из `citations` внутри текстовых блоков
  (`web_search_result_location`), а не из сырых результатов поиска
  (`web_search_tool_result.content`) — тот же принцип, что у ChatGPT
  (`url_citation` в аннотациях текста, а не сырой список результатов
  инструмента): в отчёт идёт то, что модель реально процитировала, а не всё,
  что было найдено.

## Последствия

- `packages/core/src/contracts/engine.ts` — `EngineId` расширен значением
  `'claude'`. Это интерфейс адаптеров движка — инвариант; изменение сделано
  через это ADR, как того требует CLAUDE.md.
- `packages/config/src/engines.v1.json`, `audit-profiles.v2.json` — Claude
  добавлен в реестр движков и в список движков `standard`/`extended`; список
  внешних провайдеров и ключей (инвариант) пополнен Anthropic.
- Надбавка за дополнительную локаль расширенного профиля поднята с $3/$4 до
  $4/$5 — с четырьмя движками на локаль себестоимость дополнительной локали
  выросла (юнит-экономика версии 1.4, раздел 3.3).
- Замер расхождения между Haiku 4.5 и более крупной моделью Claude — на неделе 5,
  тем же порядком, что и для ChatGPT (Luna против Sol); решение о переходе
  фиксируется отдельным ADR.
