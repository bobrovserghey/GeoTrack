# ADR-007. Merchant of record Paddle с запасным вариантом

Дата: 2026-09-11. Статус: принято.

## Контекст

Нужен платёжный провайдер с MoR (налоги на стороне провайдера) для международных продаж без юридической нагрузки на ИП.

## Решение

Paddle как основной MoR. Запасной — Lemon Squeezy. Первые пять клиентов при задержке одобрения Paddle — ручные счета.

## Причины

- MoR снимает НДС и налоги за пределами РО
- Webhook-архитектура: платёжный статус определяет аудит, не возврат пользователя

## Последствия

Обработка вебхука идемпотентна по `event_id` и по заказу. Подпись вебхука проверяется всегда. Цена берётся с сервера по `product_id`.

## Поправка 2026-10-01

Подтверждено первым реальным прогоном против Paddle sandbox (чекаут →
оплата тестовой картой → вебхук → возврат, см. «Поправка 2026-10-01» в
`docs/specs/T-45.md`):

- Paddle Billing не предоставляет хостингового checkout-редиректа без
  JavaScript на странице продавца — `@paddle/paddle-js` обязателен для
  любого веб-чекаута через Transactions API, это не опциональная
  клиентская SDK-обёртка, а единственный способ открыть оплату. T-45
  изначально предполагал обратное (см. поправку в T-45.md) — ошибка
  устранена той же правкой.
- Sandbox и production у Paddle — полностью разделённые окружения с
  разными базовыми URL (`sandbox-api.paddle.com` /
  `api.paddle.com`) и разными ключами, не взаимозаменяемыми. Код выбирает
  URL по префиксу API-ключа (`pdl_sdbx_` / `pdl_live_`), а не по
  отдельному конфигурационному флагу.
- Возврат (`POST /adjustments`, `type: 'full'`) подтверждён против
  реального sandbox API без изменений формы запроса. Ответ приходит со
  статусом `pending_approval`, не мгновенным `approved` — возврат не
  завершается синхронно с нажатием кнопки в админке.
- Оверлей Paddle.js открывается только с домена, внесённого в approved
  domains / default payment link в дашборде Paddle (Checkout → Checkout
  settings). Перед подключением реального домена его нужно добавить там,
  иначе кнопка покупки молча не сработает. Для sandbox-тестов достаточно
  любого домена, в том числе адреса туннеля.
