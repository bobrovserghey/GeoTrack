# ADR-016. Лента прогресса через опрос (polling)

Дата: 2026-09-11. Статус: принято.

## Контекст

Пользователь должен видеть ход выполнения аудита в реальном времени. Нужна простая реализация без WebSocket и SSE.

## Решение

Клиент опрашивает `/api/progress?token={progressToken}` каждые 2 секунды. Ответ: список событий с монотонным `seq`, начиная с переданного `after_seq`. Прогресс-токен выдаётся при создании аудита, короткоживущий.

## Причины

- Проще SSE и WebSocket при агентной разработке
- Обрыв любой длины восстанавливает ленту без пропусков — клиент запоминает последний `seq`
- `audit_events` — только лента, не источник состояния; статус берётся из `audits.status`

## Последствия

Экран прогресса рисует каждый статус из таблицы переходов, не выводит его из событий. Лента — дополнительная детализация, не основа.
