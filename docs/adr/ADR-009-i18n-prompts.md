# ADR-009. Локализация через next-intl и место хранения промптов по локалям

Дата: 2026-09-11. Статус: принято.

## Контекст

Два рынка: Молдова (румынский) и международный (английский). Промпты движков и UI-строки должны быть локализованы.

## Решение

next-intl для UI. Промпты задач модели — файлы с версией в имени по задаче и локали в `packages/config/prompts/tasks`. Канонические наборы категорий — в `packages/config/prompts/categories`.

## Причины

- Версия промпта в имени файла = история в git без дополнительной системы
- Изменение промпта видно как diff и требует прогона eval
- `audits.prompt_set_version` позволяет воспроизвести любой старый аудит

## Последствия

Конкатенация строк в коде шага запрещена — только шаблонизатор с переменными.
