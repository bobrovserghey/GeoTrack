# ADR-006. Схема токена отчёта и модель доступа

Дата: 2026-09-11. Статус: принято.

## Контекст

Отчёт доступен по ссылке без регистрации — продуктовое решение. Нужна безопасная реализация без подбора токена и без индексации.

## Решение

Токен — 32 байта криптографического генератора, URL-safe представление. В базе хранится хэш. Страница собирается сервером по хэшу при каждом открытии. Запрет индексации. Строгая политика реферера.

## Причины

- Утечка дампа не даёт доступа к отчётам (хранится хэш)
- Отчёт не хранится как файл — перезапуск шага автоматически дополняет его
- Каждое открытие собирается из данных — можно показать в новой версии методологии

## Последствия

Токен прогресса — отдельный, короткоживущий. PDF рендерится через внутренний маршрут с сервисным секретом.
