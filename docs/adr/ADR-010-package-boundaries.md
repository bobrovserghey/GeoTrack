# ADR-010. Границы пакетов и правило зависимостей

Дата: 2026-09-11. Статус: принято.

## Контекст

Монорепозиторий с несколькими пакетами. Нужно предотвратить циклические зависимости и смешение ответственностей.

## Решение

`core` не импортирует ничего из `apps`. `web` и `worker` не импортируют друг друга. Общий UI — в `packages/ui`. Нарушение ловится линтером, не ревью.

## Причины

- `core` тестируется без инфраструктуры
- `ui` гарантирует, что PDF и веб-отчёт не разойдутся
- Линтер надёжнее ревью при агентной разработке

## Последствия

Линтер проверяет также импорт `undici` и `playwright` мимо модулей из ADR-015.
