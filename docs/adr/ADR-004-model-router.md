# ADR-004. Роутер моделей и выбор основной малой модели

Дата: 2026-09-11. Статус: принято.

## Контекст

Слой извлечения должен быть модельно-независимым для сравнения провайдеров и смены без переписывания кода.

## Решение

Таблица `{задача → модель, запасная модель}` в `packages/config`; одна функция возвращает адаптер по имени задачи. Основная малая модель — Gemini Flash. Адаптер ChatGPT использует модель среднего класса (не флагман).

## Причины

- Смена модели = правка одной строки конфигурации + прогон eval
- Флагман ChatGPT удваивает стоимость промаха кэша и ломает потолок стандартного профиля
- Gemini Flash дешевле и имеет 5 000 бесплатных grounding-запросов в месяц

## Последствия

На неделе 5 сравниваем среднюю модель с флагманом на пяти эталонных сайтах; результат в ADR о переходе.
