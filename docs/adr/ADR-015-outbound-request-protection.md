# ADR-015. Защита исходящих запросов воркера (safe-fetch и фабрика Playwright)

Дата: 2026-09-11. Статус: принято.

## Контекст

Воркер ходит на произвольные URL из пользовательского ввода. Это главная SSRF-угроза продукта.

## Решение

Два модуля — единственные точки исходящих запросов в воркере. Нарушение ловится линтером.

**`core/net/safe-fetch`**: резолв всех адресов → отклонение любого приватного IP → соединение на проверенный адрес (закрепление). Ручная обработка редиректов (до 5). Таймаут 15 с, тело 2 МБ, пауза 1 с между запросами к домену.

**Фабрика Playwright**: перехват всех запросов через `route`, запрет IP-литералов, проверка хоста тем же резолвером, блокировка media/font/websocket.

**Изоляция воркера**: приватная сеть Railway отключена. Проверка при старте — воркер не поднимается при доступной приватной сети.

## Причины

- Подмена адреса между резолвом и соединением (TOCTOU) закрыта закреплением адреса
- Без изоляции воркера Playwright-резолв в Chromium обходит Node-проверки

## Последствия

Тесты пишутся до кода по всем случаям раздела 9.2 tech-плана.
