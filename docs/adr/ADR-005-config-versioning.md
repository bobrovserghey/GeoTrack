# ADR-005. Формат и версионирование конфигурации весов

Дата: 2026-09-11. Статус: принято.

## Контекст

Веса, пороги, формула интервала и правила блокеров должны меняться продактом без цикла разработки и сохранять возможность пересчёта старых аудитов.

## Решение

`packages/config/methodology.v1.json` — единый файл конфигурации. Каждый аудит сохраняет `methodology_version`. Скоринг — чистая функция от фактов и версии конфигурации.

## Причины

- Продакт правит данные, не код
- Любой старый аудит можно пересчитать новой версией и сравнить
- Калибровка на неделе 9 не требует деплоя

## Последствия

Изменение веса — это изменение данных с ADR-записью; код скоринга не меняется.
