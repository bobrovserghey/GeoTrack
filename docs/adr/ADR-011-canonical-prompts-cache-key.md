# ADR-011. Канонические наборы промптов категорий и ключ кэша

Дата: 2026-09-11. Статус: принято.

## Контекст

Главный рычаг снижения себестоимости — кэш ответов движков по категории. Нужен стабильный ключ, не зависящий от конкретного сайта.

## Решение

Промпты категории — фиксированный набор из 40 по идентификатору (не по тексту). Ключ кэша: `category_id, locale, prompt_set_version, prompt_id, engine_id`. Брендовые промпты не кэшируются никогда. TTL 14 дней.

## Причины

- Ключ по идентификатору, а не по тексту: смена формулировки промпта — новая версия набора, а не промах кэша
- Изоляция по локали и версии: нет смешения языков и версий
- Брендовые промпты уникальны для сайта — кэш не применим

## Последствия

Обязательные тесты: попадание, промах, истечение, дозапрос повторов, отсутствие брендовых промптов в кэше, отсутствие смешения локалей, отсутствие смешения версий.
