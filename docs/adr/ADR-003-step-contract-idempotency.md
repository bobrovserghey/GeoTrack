# ADR-003. Контракт шага пайплайна и правило идемпотентности

Дата: 2026-09-11. Статус: принято.

## Контекст

14 шагов пайплайна должны быть тестируемы без инфраструктуры, идемпотентны и единообразны.

## Решение

Каждый шаг — `Step<I,O> = (input: I, ctx: StepContext) => Promise<StepResult<O>>`. Ключ идемпотентности — `audit_id + шаг + версия`. Повторный запуск не дублирует записи и не тратит деньги.

## Причины

- Единый контракт позволяет тестировать любой шаг без реальной очереди
- Идемпотентность — основа безопасного перезапуска из админки
- `StepContext` инжектирует зависимости: логгер, профиль, бюджет

## Последствия

Шаг никогда не создаёт соединений и не читает env напрямую. Нарушение проверяется тестом «шаг не импортирует env».
