# ADR-008. Политика фикстур и запрет сетевых вызовов в тестах

Дата: 2026-09-11. Статус: принято.

## Контекст

Тесты должны быть воспроизводимы, дешевы и не зависеть от внешних сервисов.

## Решение

Любой сетевой вызов в тестах запрещён на уровне окружения — заглушка бросает исключение. Фикстуры записываются скриптом `pnpm fixtures:record` и коммитятся. Живые вызовы — отдельный ночной прогон.

## Причины

- Делает невозможным случайный дорогой вызов в CI
- Фикстуры — документация реального поведения провайдеров
- Обновление фикстуры — отдельный PR с объяснением

## Последствия

Молчаливое обновление фикстуры под падающий тест запрещено. Это правило в CI.
