# ADR-014. Доставка платного отчёта при сбоях

Дата: 2026-09-11. Статус: принято.

## Контекст

Клиент заплатил и ожидает отчёт. Нужны чёткие правила для четырёх классов сбоев.

## Решение

| Класс | Правило |
|---|---|
| Частичный столп | Отчёт доставляется, столп помечен, интервал расширен. Без возврата |
| Жёсткий потолок стоимости | Как частичный столп. Статус `needs_attention` до доставки |
| Фатальный сбой | `needs_attention` + алерт. Админ: перезапуск или возврат через API Paddle |
| Ручная проверка > 24 часов | Чистый аудит уходит автоматически; аудит с пометками ждёт |

Письмо «оплата получена» уходит сразу после вебхука. Полный возврат — если отчёт не доставлен за 48 часов или после фатального сбоя.

## Причины

- Держать оплаченный отчёт > 24 часов из-за ручной проверки вредит больше, чем возможная опечатка
- Частичный столп — не основание для возврата: методология предусматривает неизмеренные критерии

## Последствия

Автоотправка после 24 часов — единственное исключение из правила «ручная проверка обязательна».
