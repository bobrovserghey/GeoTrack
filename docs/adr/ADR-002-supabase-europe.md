# ADR-002. Supabase как база, хранилище и аутентификация; регион Европа

Дата: 2026-09-11. Статус: принято.

## Контекст

Нужны база данных, файловое хранилище для артефактов и аутентификация для админки. Один человек, нет времени на управление инфраструктурой.

## Решение

Supabase (Postgres + Storage + Auth) в европейском регионе с первого дня.

## Причины

- Managed-сервис: нет операционной нагрузки
- RLS встроен — главная защита данных
- Европейский регион бесплатен сейчас; перенос позже стоит недель простоя
- Drizzle работает поверх стандартного Postgres

## Последствия

Переход на Cloudflare R2 для хранилища откладывается на фазу 3. DPA и mid-market продажи — фаза 3.
