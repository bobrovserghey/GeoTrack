# ADR-027 — DataForSEO как источник ответов движков и поисковых данных

**Статус:** Предложено
**Дата:** 2026-10-03
**Контекст:** решение продакта 2026-10-03; техплан версии 1.9; затрагивает T-07, T-18, T-27, T-28, T-78, ADR-011, ADR-017, ADR-019, ADR-020, ADR-024

> **Статус.** Этот ADR не принят. Статус «принято» ставит продакт. До этого
> момента документ фиксирует предложение и его последствия, а не действующее
> архитектурное решение. Код по нему не менялся: адаптера DataForSEO в
> репозитории нет (проверено 2026-10-03 — вендор не упомянут ни в одном файле
> кода и конфигурации).

> **Изменение инварианта.** Решение меняет защищённый список внешних
> провайдеров и ключей в CLAUDE.md (сегодня: Perplexity, OpenAI, Google,
> Anthropic, SerpAPI, Paddle, Supabase, Resend). По правилам проекта такое
> изменение требует явного письменного согласия продакта в описании PR — тот
> же прецедент, что Claude как четвёртый движок (ADR-024) и Resend (ADR-026).
> Кроме того затрагивается интерфейс `EngineAdapter` — тоже инвариант.

## Контекст

**Что решено продактом 2026-10-03.** Данные об ответах движков и поисковые
проверки идут через DataForSEO. Гипотеза проверяется на одном движке.
Стоимость критична для MVP — это и есть причина пересмотра.

**Что построено сегодня (проверено по репозиторию 2026-10-03).** Четыре
адаптера прямых API провайдеров в `packages/core/src/adapters`: `perplexity.ts`,
`chatgpt.ts`, `gemini.ts`, `claude.ts`, плюс `gemini-model.ts` для малой
модели. Поисковые проверки — SerpAPI из двух шагов воркера,
`apps/worker/src/steps/tech-check.ts` и `offsite-signals.ts`. Профили
(`packages/config/src/audit-profiles.v2.json`): у тизера один движок
`perplexity`, 1 повтор, бюджет 90 секунд, 2 запроса SerpAPI; у `standard` и
`extended` — четыре движка, 2 повтора, 11 запросов SerpAPI, бюджеты 360 и 480
секунд. Ни один адаптер и ни один из этих шагов не вызывается из пайплайна:
шаги оркестратора `audit-run` — заглушки (T-79).

**Условия и цены DataForSEO (проверено по документации вендора 2026-10-03).**

LLM Scraper. Эндпоинт
`POST https://api.dataforseo.com/v3/ai_optimization/chat_gpt/llm_scraper/live/advanced`,
Basic-авторизация (ключи в `app.dataforseo.com/api-access`). «Each Live ChatGPT
LLM Scraper API call can contain only one task», «You can send up to 2000 API
calls per minute». Параметры: `keyword` (обязателен, «up to 2000 characters»,
URL-кодирование), `location_name` или `location_code`, `language_name` или
`language_code`, `force_web_search` (optional boolean, по умолчанию `false`),
`tag` (до 255 символов). Поиск принудительно отключить нельзя; при
`force_web_search: true` «there is no guarantee web sources will be cited».
Ни выбора модели, ни системного промпта в параметрах нет. Поля ответа:
`markdown`, `sources` (title, domain, url, publication_date), `search_results`,
`fan_out_queries`, `brand_entities` (бренды с категорией и URL), `items`
(`chat_gpt_text`, `chat_gpt_table`, `chat_gpt_images` и другие), `model`
(«indicates the model version»), `check_url`, `datetime` в UTC и `cost` —
стоимость задачи в USD. Движков у скрейпера два: ChatGPT и Gemini (у каждого
своя ветка документации, у Gemini тоже живой метод до 120 секунд и
стандартный метод). Механизм: обзорная страница AI Optimization говорит, что
Scraper получает результаты «through web scraping»; на странице
ChatGPT-скрейпера механизм не назван. Песочница бесплатна («Your account will
not be charged»), адрес `https://sandbox.dataforseo.com/v3/`, структура
ответа та же, данные фиктивные, лимиты те же (2000 вызовов в минуту, 100
задач на стандартный POST, 1 для живого метода).

Цены и время исполнения LLM Scraper:

| Режим | Время | Цена за результат |
|---|---|---|
| Очередь | До 45 минут | $0,0012 |
| Приоритетная очередь | До 5 минут | $0,0024 |
| Живой | Расхождение вендора: документация API — «up to 120 seconds», страница цен — «до 90 секунд» | $0,004 |

LLM Responses — отдельное семейство методов того же вендора поверх
официальных API провайдеров (ChatGPT, Claude, Gemini, Perplexity). Живой
режим: «$0.0006 + price charged by LLM». Очередь: «$0.0002 + $0.01» —
предоплата, разница возвращается, если тариф провайдера оказался меньше.

**Условия провайдеров, которые делают прямой путь неудобным.**

Условия Gemini API (ai.google.dev/gemini-api/terms), дословно: «You will not,
and will not allow your end user or any third party to, cache, frame,
syndicate, resell, analyze, train on, or otherwise learn from Grounded Results
or Search Suggestions» — с ограниченным исключением: хранение текста до 2 лет
для оценки, оптимизации и истории чата. Показывать Grounded Results разрешено
только «to the end user who submitted the prompt». И отдельно: «You may use
only Paid Services when making API Clients available to users in the European
Economic Area, Switzerland, or the United Kingdom».

Perplexity (docs.perplexity.ai, страница chat completions), подтверждено
официально: «Sonar Chat Completions support ended on September 27, 2026.»
Замена — Agent API, эндпоинт `/v1/agent`; вендор рекомендует переводить и
существующее использование, и все новые проекты. Синхронные и потоковые
запросы продолжают работать: «they are being reformulated as Agent API
requests»; асинхронные не переформулируются и не поддерживаются. Это дата до
правки: тизер в профилях построен на единственном движке `perplexity` с
моделью `sonar` (`packages/config/src/engines.v1.json`,
`packages/core/src/adapters/perplexity.ts` — `const PERPLEXITY_MODEL =
'sonar'`, запрос синхронный). Адаптер, вероятно, ещё работает, потому что
синхронные запросы переформулируются вендором, но это предположение: живого
прогона не было.

**Оценка стоимости (ОЦЕНКА, не замер; один движок, один повтор, LLM
Scraper).** Тизер на 12 ответов — $0,014 в очереди и $0,048 в живом режиме;
при кэше категории остаются 2 брендовых ответа — $0,002 и $0,008. Полный
аудит на 30 ответов в приоритетной очереди — $0,072; при кэше категории (20
ответов из кэша) — $0,024. Тизер целиком, вместе с извлечением, паспортом и
проверкой индекса — $0,024–0,072.

## Решение

Ответы движков и поисковые проверки получаются от одного вендора, DataForSEO:
LLM Scraper — для ответов движков, SERP-методы — вместо SerpAPI.

## Причины

- **Стоимость.** Результат скрейпера стоит $0,0012–0,004 независимо от длины
  ответа и от того, искал движок в вебе или нет. Прямые API платят за токены и
  отдельно за вызов инструмента поиска (у Claude — $0,01 за вызов, ADR-024), и
  потолки стоимости профиля ($0,10 и $0,25 у тизера) упираются именно в это.
- **Один контракт вместо пяти.** Одна Basic-авторизация вместо ключей
  Perplexity, OpenAI, Google, Anthropic и SerpAPI; поле `cost` в ответе даёт
  стоимость задачи в USD, то есть учёт стоимости перестаёт зависеть от нашей
  прайс-таблицы `provider-prices.v1.json`.
- **Условия Google.** Прямое использование Gemini с grounding ограничено
  запретом кэшировать и анализировать Grounded Results и правилом показывать
  их только тому, кто отправил промпт. Наш кэш категорий (ADR-011) и цитаты
  движка в отчёте клиента — ровно эти два действия. Снимает ли посредник это
  ограничение — открытый вопрос, не вывод этого ADR.
- **Sonar.** Поддержка Chat Completions, на которой стоит адаптер тизера,
  закончилась 27 сентября 2026. Любой из путей (Agent API, другой движок
  тизера, DataForSEO) — работа; этот путь закрывает её вместе с остальными
  движками.
- **Готовые поля вендора.** `sources`, `brand_entities` и `fan_out_queries`
  дают то, что мы сегодня добываем малой моделью из текста ответа. Это
  РЕКОМЕНДАЦИЯ: отказываться от извлечения моделью — только после живого теста
  качества.

## Последствия

**Что упрощается.**

- Один провайдер и один ключ вместо пяти в обязательных переменных окружения;
  учёт стоимости — по полю `cost`, а не по собственной прайс-таблице.
- Бесплатная песочница с идентичной структурой ответа годится для записи
  фикстур (ADR-008) без списаний. Данные фиктивные, поэтому для калибровки и
  замера качества она не годится.
- Пропадает разнообразие форм ответа: сегодня каждый из четырёх адаптеров
  разбирает свои поля цитат (`url_citation` у ChatGPT, `citations` у Claude,
  grounding-метаданные у Gemini), и на каждое расхождение имён полей уходит
  отдельная фикстура.

**Что усложняется.**

- **Нет режима без поиска.** `force_web_search` только включает поиск.
  Индикатор «знание без поиска» (ADR-020) и список `noSearchEngines` в
  профилях (teaser — пусто, standard — `chatgpt`, extended — `chatgpt` и
  `gemini`) теряют источник данных. Шаг опроса этот список сегодня и не
  читает, то есть переделки кода тут меньше, чем переделки методологии.
- **Нет гарантии цитат.** Даже при `force_web_search: true` вендор не
  гарантирует, что веб-источники будут процитированы. Критерии, которые
  опираются на источники ответа, могут деградировать молча — нужен явный
  признак «источников нет» вместо нулевого значения.
- **Нет выбора модели.** Версия модели приходит в поле `model`. Замер
  «средняя модель против флагмана» (ADR-024, пункт 2) для этого канала
  теряет смысл, а воспроизводимость прогонов зависит от вендора.
- **Регион вместо локали.** Регион задаётся `location_code` или
  `location_name`, язык — `language_code` или `language_name`. Справочник
  локалей ADR-019 придётся сопоставлять с кодами вендора; поддержка локаций
  Румынии и Молдовы не проверялась.
- **Бюджет времени тизера.** В профиле на весь прогон тизера 90 секунд, а
  живой режим вендора называет сопоставимое время на один ответ. Очередь (до
  45 минут) и приоритетная очередь (до 5 минут) в синхронный тизер не
  укладываются. Выбор режима становится продуктовым, а не техническим.
- **Один вендор на критическом пути.** Его сбой останавливает и столп A, и
  поисковые проверки. Скрейпинг интерфейсов по своей природе хрупок, а ответы,
  полученные без входа в аккаунт, могут отличаться от того, что видит
  авторизованный пользователь.

**Что придётся переделать.**

- **`EngineAdapter` (инвариант).** Сегодня
  `packages/core/src/contracts/engine.ts` описывает `ask(prompt, { timeoutMs,
  locale })` и ответ `{ text, sources, raw, usage }`. Режима исполнения
  (живой, очередь, приоритет) в контракте нет — это новое измерение: очередь
  означает, что шаг не возвращает ответ в том же вызове, и опрос движков
  перестаёт быть одним синхронным шагом. Кода региона в контракте тоже нет.
  Правка интерфейса — отдельный PR с согласием продакта.
- **Кэш и поля вендора.** Ключ кэша категорий (ADR-011) включает движок и
  повтор; при смене источника записи, снятые прямыми API, и записи вендора
  несопоставимы — нужна либо версия источника в ключе, либо сброс кэша.
  Хранить придётся вендорские поля (`check_url`, `datetime`, `items`,
  `brand_entities`), а не только текст и источники. Запрет на кэширование
  брендовых и клиентских промптов (ADR-021, `BrandedPromptCacheError`)
  остаётся в силе.
- **Судьба четырёх адаптеров.** Не решена. У скрейпера только два движка,
  ChatGPT и Gemini, поэтому ответы Claude и Perplexity через него получить
  нельзя: либо они идут через LLM Responses (и тогда тариф провайдера
  возвращается в расчёт), либо соответствующие адаптеры остаются, либо состав
  движков в профилях меняется. Профили — защищённый файл, их правка требует
  отдельного решения. В отчёте есть блок цитаты, подписанный именем
  опрошенного движка (поле `citation.engine` в данных страницы отчёта), и смена
  состава движков меняет то, что в нём написано.
- **SerpAPI.** Шаги `tech-check.ts` и `offsite-signals.ts` обращаются к
  `serpapi.com/search.json` и передают ключ в query string (открытый пункт,
  блок D в `debt.md`). Переход на SERP-методы DataForSEO — новый адаптер и
  правка обоих шагов. `playbook/integrations.md` уже называет DataForSEO
  запасным вариантом SerpAPI «с идентичным контрактом адаптера», так что
  направление не противоречит плейбуку.
- **Список внешних провайдеров и ключей (инвариант CLAUDE.md)** пополняется
  DataForSEO; обязательные переменные окружения и тест `env-list-sync.test.ts`
  (T-00) — вместе с ним. Если какие-то прямые провайдеры уходят, их ключи
  удаляются из того же списка.
- **ADR-017 (условия хранения ответов провайдеров)** расширяется разделом
  DataForSEO: условия вендора в части хранения и показа результатов в отчётах
  не читались.
- **Реестр движков и прайс-таблица.** `engines.v1.json` (там же
  `concurrencyLimit` на провайдера и `model: "sonar"`) и
  `provider-prices.v1.json` описывают прямые API. Лимит вендора — 2000 вызовов
  API в минуту, одна задача на живой вызов; это другая модель ограничений.

## Открытые вопросы

Исход не утверждается ни одним пунктом ниже.

- **Движок теста.** РЕКОМЕНДАЦИЯ — ChatGPT через LLM Scraper. Исходное решение
  продакта 2026-10-02 называло Gemini. Решает продакт.
- **Цена на время теста.** РЕКОМЕНДАЦИЯ — $29 за полный аудит для первых 30
  покупателей при основной цене $79. Не решение.
- **Отказ от извлечения моделью** в пользу готовых полей вендора (`sources`,
  `brand_entities`) — только после живого теста качества.
- **Условия использования DataForSEO** в части хранения и показа результатов
  в отчётах: не проверено, страницы условий не читались.
- **Как вендор получает ответы Gemini** при запретах Google на кэширование и
  анализ Grounded Results: не проверено.
- **Локации Румынии и Молдовы** в LLM Scraper: не проверялось.
- **Цена поискового запроса SERP у DataForSEO:** не проверено, страница цен
  сумм не отдала. Ориентир из обсуждения — $0,0006 в очереди против $0,015 у
  SerpAPI в текущем расчёте.
- **Минимальное пополнение $50 и отсутствие подписки:** не проверено, на
  странице цен LLM Scraper этого нет.
- **Доступность grounding на бесплатном уровне для моделей Gemini 3.x:** не
  проверено, в условиях прямо не сказано.
- **Perplexity Sonar.** Поддержка Chat Completions закончилась 27 сентября
  2026. Варианты: перейти на Agent API, сменить движок тизера, дождаться
  DataForSEO. Решает продакт.
- **Судьба четырёх существующих адаптеров и SerpAPI,** а также блока цитаты
  движка в отчёте.
- **Выбор режима исполнения на канал** (лендинг, аутрич, платный аудит) и
  бюджет времени тизера при живом режиме.
