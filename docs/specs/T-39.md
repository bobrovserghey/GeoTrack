# T-39: Столп E — агентные сценарии E1

## Цель

Реализовать два скриптовых сценария для критерия E1 (Прохождение сценариев агентом):

- **`find_price`** — найти страницу с тарифами и убедиться, что цена читается агентом
- **`start_registration`** — найти и открыть форму регистрации или trial

Каждый сценарий прогоняется до 3 попыток (стоп на первом успехе). Результат фиксирует: успешность, количество попыток, список шагов, точку отказа.

## Зависимости

- T-37 (паттерн injectable Playwright-зависимостей, `CheckPageFn`)
- T-38 смёрджен; T-39 не зависит от него технически

## Шаг воркера (`apps/worker`)

Файл: `apps/worker/src/steps/agent-scenario-check.ts`

### Injectable

```ts
export type ScenarioAttemptResult = {
  success: boolean;
  steps: string[];
  failurePoint: string | null;
};

export type RunScenarioFn = (
  origin: string,
  scenario: 'find_price' | 'start_registration',
) => Promise<ScenarioAttemptResult>;

export type AgentScenarioCheckDeps = {
  runScenario: RunScenarioFn;
};

export type AgentScenarioCheckInput = {
  origin: string;
  keyPages: string[];
};
```

### Логика `runWithRetries(origin, scenario, runScenario, maxAttempts=3)`

1. Цикл до `maxAttempts` итераций.
2. Каждый вызов `runScenario` обёрнут в try/catch.
3. Успешный вызов (не бросает) инкрементирует счётчик `ran`; если `result.success === true` — немедленный возврат `{ ...result, attempts: ran }`.
4. Если вызов бросает — пробуем дальше, `ran` не меняется.
5. После цикла:
   - Если `lastResult !== null` → `{ ...lastResult, attempts: ran }` (все попытки выполнились, но ни одна не успешна)
   - Если `lastResult === null` (все бросали) → `{ success: false, attempts: 0, steps: [], failurePoint: 'runner unavailable' }`

### Логика `collectAgentScenarioCheck(input, deps)`

- Запускает `find_price` и `start_registration` **последовательно** (один Playwright-контекст безопаснее).
- `measured = findPrice.attempts > 0 || startRegistration.attempts > 0`
- Статус:
  - `'failed'` — `!measured`
  - `'partial'` — один из сценариев `attempts === 0`
  - `'ok'` — оба `attempts > 0`

## Тесты (`apps/worker/src/__tests__/agent-scenario-check.test.ts`)

| # | Сценарий | Ожидание |
|---|---|---|
| 1 | Оба сценария успешны на первой попытке | `status: 'ok'`, `measured: true`, `success: true`, `attempts: 1` |
| 2 | `find_price` успешен на 3-й попытке | `attempts: 3`, `success: true`, шаги из 3-й попытки |
| 3 | `start_registration` проваливается 3 раза (не бросает) | `success: false`, `attempts: 3`, `failurePoint` заполнен |
| 4 | Оба сценария проваливаются (не бросают) | `status: 'ok'`, `measured: true`, `success: false` для обоих |
| 5 | `runScenario` бросает для `find_price`, `start_registration` успешен | `status: 'partial'`, `findPrice.attempts === 0`, `startRegistration.success: true` |
| 6 | `runScenario` бросает для обоих | `status: 'failed'`, `measured: false`, оба `attempts === 0` |
| 7 | Шаги из успешной попытки записываются | `steps` не пустой |
| 8 | Шаги из последней неуспешной попытки записываются | `steps` содержат шаги последней попытки |
