# T-32 — Карта источников цитирования

Статус: согласовано
Неделя: 6
Источник: GEOTRACK_AUDIT_METHODOLOGY_RU.md §2.1 (A2), §Шаг 6; GEOTRACK_TECH_PLAN_MVP_RU.md §13.2

## Задача

По всем ссылкам-источникам из ответов движков (поле `sources` в
`EnginePollResponse`) построить «карту источников категории» — агрегированный
список доменов, отсортированных по частоте цитирования, с пометками клиента и
конкурентов. Карта питает критерии C и D, находки об отсутствии бренда в
цитируемых источниках и сравнение контента клиента с цитируемыми страницами.

Acceptance: карта строится для 100 % аудитов; точность нормализации домена ≥ 0,95
(уже подтверждена sources-eval в T-31 на синтетическом наборе).

## Входы и выходы

```ts
// packages/core/src/steps/source-map.ts

type SourceMapEntry = {
  domain: string;              // нормализованный домен
  citedCount: number;          // число уникальных ответов, процитировавших этот домен
  urls: string[];              // уникальные raw-URL этого домена
  promptIds: string[];         // уникальные promptId, из которых домен процитирован
  engineIds: EngineId[];       // уникальные движки
  isClientDomain: boolean;
  isCompetitorDomain: boolean;
};

type SourceMapOutput = {
  entries: SourceMapEntry[];   // отсортированы по citedCount desc
  clientCitedCount: number;    // число ответов, процитировавших домен клиента
  totalResponses: number;      // всего ответов (для A2: clientCitedCount / totalResponses)
};
```

## Алгоритм buildSourceMap

1. Для каждого `EnginePollResponse` перебрать `sources` → нормализовать URL через
   `normalizeDomain` → пропустить пустой результат.
2. Для каждого домена вести четыре множества: `responseKeys`
   (`promptId:engineId:repeatIndex`), `urls`, `promptIds`, `engineIds`.
3. Подсчитать `citedCount = responseKeys.size` (одного ответа достаточно, даже
   если в нём два URL одного домена).
4. Сравнить домен с `clientDomain` (уже нормализован) и с
   `normalizeDomain("https://" + d)` для каждого конкурента.
5. Отсортировать по `citedCount` desc, равные — по `domain` asc.
6. Вернуть `StepResult<SourceMapOutput>` со `status: 'ok'`.

Шаг детерминирован — модель не нужна. Статус всегда `ok`.

## Тесты (детерминированные)

- Пустые responses → `entries: []`, `clientCitedCount: 0`
- Response без sources → не влияет на карту
- Клиентский домен помечен `isClientDomain: true`
- Конкурентский домен помечен `isCompetitorDomain: true`
- `www.domain.com` и `domain.com` → один домен, `citedCount` агрегируется
- Два URL одного домена в одном ответе → `citedCount: 1` (не 2)
- Один домен в двух разных ответах → `citedCount: 2`
- Сортировка: более цитируемый домен выше
- `clientCitedCount` = число ответов, где клиент процитирован
