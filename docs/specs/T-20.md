# T-20 — Скоринг столпа A + доверительный интервал

## Цель

Реализовать чистую (без сети и БД) функцию скоринга для столпа A (AI-visibility) и вычисление доверительного интервала для итогового балла.

## Зависимости

- T-16 — столп B уже выполнен (`pillar-b.ts`), паттерн переиспользуется
- T-19 — `EngineResponseFacts` как источник фактов

## Входные данные `scorePillarA`

```ts
scorePillarA(
  facts: EngineResponseFacts[],
  config: Methodology,
  clientDomain: string,
): PillarAResult
```

## Критерии столпа A

| ID  | maxScore | Формула                                                                 | Когда unmeasured  |
|-----|----------|-------------------------------------------------------------------------|-------------------|
| A1  | 20       | `count(brandMentioned) / total × maxA1`                                 | facts.length === 0 |
| A2  | 15       | `count(citedDomains ∋ clientDomain) / total × maxA2`                   | facts.length === 0 |
| A3  | 15       | `avg(normalizedPositionScore where ≠ null) / 100 × maxA3`              | нет ни одного ответа с позицией |
| A4  | 20       | `brandMentionCount / (brandMentionCount + competitorMentionCount) × maxA4` | оба = 0        |
| A5  | 15       | — (unmeasured до T-30)                                                  | всегда           |
| A6  | 15       | — (unmeasured до T-31)                                                  | всегда           |

- `brandMentionCount` = число ответов, где `brandMentioned = true`
- `competitorMentionCount` = сумма `count` по всем конкурентам по всем ответам
- Unmeasured критерии **исключаются из знаменателя** `pillarScore`
- `pillarScore = round(measuredScoreSum / measuredMaxSum × 100)`, 0 если measuredMaxSum = 0

## Выходные данные

```ts
type PillarAResult = {
  criterionScores: Record<'a1'|'a2'|'a3'|'a4'|'a5'|'a6', CriterionScore>;
  pillarScore: number;       // 0–100
  measuredMaxSum: number;
  unmeasuredCriteria: string[];
};
```

## Доверительный интервал `computeInterval`

```ts
computeInterval(
  pillarAScores: number[],        // один балл (0-100) на каждую группу повторений
  unmeasuredWeightFraction: number, // доля maxScore unmeasured / total maxScore
  config: Methodology,
): { half: number; low: number; high: number }
```

Формула (итог в единицах шкалы 0–10):

```
h_rep = hRepFactor × σ_A / 10     (если repeats ≥ 2)
h_rep = hRepFallback               (если 1 повторение)
h_cov = 10 × hCovFactor × w_unm
half  = h_rep + h_cov
center = mean(pillarAScores) / 10
low   = max(0, center − half)
high  = min(10, center + half)
```

Константы из `methodology.v1.json → interval`: `hRepFallback=0.3`, `hCovFactor=0.5`, `hRepFactor=0.3`.
