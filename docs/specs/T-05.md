## Orchestrator flow (stub audit)

1. `status.running` — `queued → running`, seq event
2. `crawl.stub` — пишет step.started + step.completed события
3. `status.waiting-category` — `running → waiting_category`
4. `step.waitForEvent('wait-category', timeout: '10m')` — ждёт `geotrack/audit.category.selected`
5. `status.running-after-category` — `waiting_category → running` (user/auto-select), флаг `autoSelected`
6. `engine-poll.stub` — пишет step.started + step.completed события
7. `status.completed` — `running → completed`
8. `status.in-review` — только платные: `completed → in_review`

## Acceptance criteria

- Каждый разрешённый переход покрыт тестом ✓
- Каждый запрещённый переход из терминального состояния покрыт тестом ✓ (3×16 = 48 тестов)
- Таймаут категории работает на фикстурном времени: `step.waitForEvent → null` → `autoSelected: true` ✓
- Пустой аудит проходит от события до записи: статусы queued→running→waiting_category→running→completed ✓
- Платный аудит дополнительно переходит в `in_review` ✓
