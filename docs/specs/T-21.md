# T-21 — Лендинг и форма ввода URL

## Назначение

Лендинг (`/`) принимает URL веб-приложения, проверяет Cloudflare Turnstile, создаёт запись аудита в БД и запускает Inngest-пайплайн. Пользователь перенаправляется на страницу прогресса аудита.

## Дизайн

Эталонный HTML: `Geotrack_UI.zip / pages / S1_Landing_Page.html`. Правило CLAUDE.md «Дизайн 1:1» — любые отклонения от дизайна допускаются только с явного письменного согласия продакта.

## Приёмочные критерии

1. Отправка формы без валидного Turnstile-токена → ответ 400, аудит не создаётся.
2. Отправка формы с невалидным URL → ответ 422, аудит не создаётся.
3. Успешная отправка → запись аудита в БД со статусом `queued`, событие `geotrack/audit.queued` отправлено в Inngest, ответ 201 c `{ auditId }`.
4. Страница рендерится без JS (Next.js SSR), форма интерактивна после гидрации.

### API: POST /api/audits

**Тело запроса:**
```json
{ "url": "https://example.com", "turnstileToken": "..." }
```

**Логика:**
1. Валидировать `url` через `new URL()`.
2. Верифицировать `turnstileToken` через `https://challenges.cloudflare.com/turnstile/v0/siteverify` (только если `TURNSTILE_SECRET_KEY` задан — иначе пропустить для dev).
3. Нормализовать домен через `normalizeDomain()` из `@geotrack/core`.
4. Прочитать профиль `teaser` через `getAuditProfile('teaser')` из `@geotrack/config`.
5. Прочитать методологию через `getMethodology()` → взять `version`.
6. Вставить запись в `audits` (profile: teaser, profileVersion: 1, methodologyVersion: '1', isInternal: false).
7. Отправить `inngest.send({ name: 'geotrack/audit.queued', data: { auditId } })`.
8. Вернуть `201 { auditId }`.

### Env-переменные

| Переменная | Назначение |
|-----------|-----------|
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | Публичный ключ Turnstile (клиент) |
| `TURNSTILE_SECRET_KEY` | Секретный ключ Turnstile (сервер) |
| `INNGEST_EVENT_KEY` | Ключ для отправки событий в Inngest (prod) |
| `DATABASE_URL` | PostgreSQL connection string |

### Turnstile

Клиент: `@marsidev/react-turnstile` (React-обёртка).
Виджет встраивается в форму между строкой ввода URL и кнопкой «Add category». Токен хранится в React-состоянии и отправляется вместе с URL при сабмите.

### Форма

- Accordion «Add category and competitors (optional)» — скрытый раздел, по-умолчанию закрыт.
- FAQ accordion — 6 вопросов, каждый открывается/закрывается независимо.
- При успешном сабмите → redirect на `/report/{auditId}` (страница прогресса, T-22).
