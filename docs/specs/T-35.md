# T-35 — Скоринг столпа C

## Статус

В разработке

## Зависимости

- T-33 (content-check — ContentCheckFacts)
- T-34 (cited-pages — CitedPagesOutput)

## Зачем

Преобразует сырые факты C1–C6 (из T-33) и медианы цитируемых страниц (из T-34) в числовой скор столпа C. Следует паттерну `scorePillarB` / `scorePillarA` из `packages/core/src/scoring/`.

## Вход

```ts
scorePillarC(
  contentFacts: ContentCheckFacts,  // из T-33
  citedPages: CitedPagesOutput,     // из T-34
  config: Methodology,              // packages/config/src/methodology.v1.json
): PillarCResult
```

## Конфигурация из methodology.v1.json

```json
"C": {
  "weight": 0.15,
  "criteria": {
    "c1": { "maxScore": 20 },
    "c2": { "maxScore": 20 },
    "c3": { "maxScore": 15 },
    "c4": { "maxScore": 15 },
    "c5": { "maxScore": 15 },
    "c6": { "maxScore": 15 }
  }
}
```

Итого maxScore = 100. Блокеров для столпа C нет.

## Тип результата

```ts
export type PillarCResult = {
  criterionScores: Record<'c1' | 'c2' | 'c3' | 'c4' | 'c5' | 'c6', CriterionScore>;
  pillarScore: number;       // 0–100
  measuredMaxSum: number;
  unmeasuredCriteria: string[];
};
```

`CriterionScore` переиспользуется из `pillar-b.ts`.

## Правила скоринга по критерию

### C1 — Покрытие intent-страниц (maxScore 20)

- `coveredCount` = 6 − `gapTypes.length`
- `score` = `Math.round(coveredCount / 6 * maxScore)`
- `measured: true` всегда (ContentCheckFacts.c1 присутствует)

### C2 — Структура «ответ сначала» (maxScore 20)

Вычислить `clientStructureRatio` по клиентским страницам:
- `answerFirstRatio` = pages с `hasAnswerFirstParagraph` / total client pages
- `questionHeadersRatio` = pages с `hasQuestionHeaders` / total
- `listsOrTablesRatio` = pages с `hasListsOrTables` / total
- `clientStructureRatio` = среднее трёх

`citedStructureRatio` из `CitedPagesOutput`:
- `(medianHasAnswerFirstParagraphRatio + medianHasListsOrTablesRatio) / 2`
  (только два сигнала из трёх есть в T-34 выходе)

Если `citedPages.analyzedPageCount > 0`:
- `score` = `Math.min(clientStructureRatio / Math.max(citedStructureRatio, 0.01), 1) * maxScore`, округлить
- Если `citedStructureRatio === 0`: `score` = `Math.round(clientStructureRatio * maxScore)`

Если `citedPages.analyzedPageCount === 0` (нет данных):
- `score` = `Math.round(clientStructureRatio * maxScore)`

`measured: contentFacts.c2.pages.length > 0`

### C3 — Плотность статистики (maxScore 15)

- `clientMedian` = `contentFacts.c3.medianNumericFactsPer1kWords`
- `citedMedian` = `citedPages.medianNumericFactsPer1kWords`

Если `citedPages.analyzedPageCount > 0`:
- `score` = `Math.round(Math.min(clientMedian / Math.max(citedMedian, 1), 1) * maxScore)`

Если нет данных цитируемых страниц — абсолютная шкала:
- `>= 10` → maxScore; `>= 5` → round(10/15*maxScore); `>= 2` → round(5/15*maxScore); иначе 0

`measured: contentFacts.c3.pages.length > 0`

### C4 — Свежесть контента (maxScore 15)

- `clientAgeDays` = `contentFacts.c4.medianAgeDays`
- `citedAgeDays` = `citedPages.medianAgeDays`
- `measured` = `clientAgeDays !== null`

Если `measured` и `citedAgeDays !== null`:
- `client <= cited` → maxScore
- `client <= 2 * cited` → `Math.round(maxScore * 0.75)`
- `client <= 3 * cited` → `Math.round(maxScore * 0.5)`
- иначе → `Math.round(maxScore * 0.25)`

Если `measured` но нет данных цитируемых страниц — абсолютная шкала:
- `<= 30` дней → maxScore; `<= 90` → 12; `<= 180` → 8; `<= 365` → 4; иначе → 0

Если `!measured` → `score = 0`, `measured = false`

### C5 — Ясность сущности (maxScore 15)

- По одному баллу за каждый из трёх флагов (`maxScore / 3 = 5` каждый):
  - `entityMentioned`
  - `categoryMentioned`
  - `targetAudienceMentioned`
- `score` = сумма
- `measured` = `contentFacts.c5.testedText.length > 0`

### C6 — Читаемые URL (maxScore 15)

- `score` = `Math.round(contentFacts.c6.readableUrlRatio * maxScore)`
- `measured` = `contentFacts.c6.pages.length > 0`

## Итоговый скор столпа

`pillarScore` = `measuredScoreSum / measuredMaxSum * 100` округлить.
Если `measuredMaxSum === 0` → `pillarScore = 0`.

## Тесты

1. **C1 full coverage** — 0 gapTypes → score = maxScore.
2. **C1 partial** — 3 gapTypes → score = Math.round(3/6 * 20) = 10.
3. **C1 no pages** — 6 gapTypes → score = 0.
4. **C2 client > cited** — clientStructureRatio = 0.8, citedStructureRatio = 0.5 → score = maxScore.
5. **C2 no cited data** — analyzedPageCount = 0, clientStructureRatio = 0.6 → score = Math.round(0.6 * 20) = 12.
6. **C2 unmeasured** — 0 client pages → measured = false.
7. **C3 client >= cited** — clientMedian = 10, citedMedian = 8 → score = maxScore.
8. **C3 no cited data absolute scale** — clientMedian = 6 → score = Math.round(10/15*15) = 10.
9. **C4 client fresher than cited** — clientAgeDays = 20, citedAgeDays = 30 → score = maxScore.
10. **C4 client older than cited 3x** — clientAgeDays = 100, citedAgeDays = 30 → score = Math.round(15*0.25) = 4 (исправить: 100 > 3*30=90, иначе 0).
11. **C4 null ageDays** → measured = false.
12. **C5 all three true** → score = maxScore.
13. **C5 one true** → score = 5.
14. **C5 testedText empty** → measured = false.
15. **C6 all readable** — readableUrlRatio = 1 → score = maxScore.
16. **C6 half readable** — readableUrlRatio = 0.5 → score = 8 (round(0.5*15)=8).
17. **pillarScore** — все measured, проверить сумму и нормировку.
18. **unmeasuredCriteria** — c4 и c6 unmeasured → оба в списке.

## Критерий приёмки

Модульные тесты критериев зелёные (из роудмэпа: «Модульные тесты критериев зелёные»).
