# T-31 — A6 тональность + золотые наборы упоминаний и источников

Статус: согласовано
Неделя: 5
Источник: GEOTRACK_AUDIT_METHODOLOGY_RU.md §2.1 (A6); GEOTRACK_TECH_PLAN_MVP_RU.md §5.4, §13.2

## Задача

Реализовать критерий A6 (тональность и контекст): для каждого ответа движка,
в котором бренд упомянут, модель классифицирует тональность — `positive`
(рекомендует), `neutral` (упоминает нейтрально) или `negative` (предупреждает
или отзывается негативно). Оценка A6 считается как взвешенная доля:
`(positive + 0.5 × neutral) / total × maxScore`.

Дополнительно создать синтетические золотые наборы и eval-харнессы для
упоминаний бренда и источников (детерминированные, без API-ключа), которые
были запланированы в T-19 и теперь получают код.

## Входы и выходы

```ts
// packages/core/src/steps/tone-check.ts
type Tone = 'positive' | 'neutral' | 'negative';

type ToneFact = {
  promptId: string;
  engineId: EngineId;
  repeatIndex: number;
  tone: Tone;
};

type ToneCheckOutput = {
  facts: ToneFact[];
  positiveRate: number;  // positive / total
};
```

Параметры из профиля: не требуются (A6 всегда считается по brand-mentioned ответам).

## Алгоритм classifyTone

1. Отфильтровать `responses` по `brandMentioned === true` через `mentionFacts` (ключ `promptId:engineId:repeatIndex`).
2. Для каждого отфильтрованного ответа вызвать модель с промптом классификации тональности, получить JSON `{ "tone": "positive" | "neutral" | "negative" }`.
3. При ошибке парсинга — тональность не добавляется в факты, ключ в `partialKeys`, статус `partial`.
4. Возвращает `StepResult<ToneCheckOutput>`.

## Формула scoreA6

```
weighted = positive_count + 0.5 × neutral_count
score = round(weighted / total × maxScore)
```
Если `toneFacts.length === 0` → `{ score: 0, measured: false }`.

## Интеграция в scorePillarA

`scorePillarA` получает 5-й параметр `toneFacts: ToneFact[] = []`.
Backward-compat: без параметра a6 остаётся unmeasured (как сейчас).

## Критерий приёмки

- `classifyTone` возвращает `ToneFact` для каждого brand-mentioned ответа с парсингом.
- Ошибки парсинга → `partial`, не добавляются в факты (не считаются ни за что).
- `scoreA6([], max)` → `{ score: 0, measured: false }`.
- `scoreA6([positive, positive, neutral], 15)` → `round((2 + 0.5) / 3 × 15) = 13`.
- `scoreA6([negative, negative], 15)` → `{ score: 0, measured: true }`.
- `scorePillarA(facts, config, domain)` — a6 unmeasured (backward compat).
- `scorePillarA(facts, config, domain, [], toneFacts)` — a6 measured.
- Eval: accuracy ≥ 0.80 на 100 синтетических примерах.
