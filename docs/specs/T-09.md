# T-09 — Минимальная админка

## Scope

- `apps/web/package.json` — добавлены `@geotrack/core`, `@geotrack/db`, `drizzle-orm`, `postgres`
- `apps/web/src/lib/db.ts` — синглтон Drizzle клиент
- `apps/web/src/lib/admin-auth.ts` — хэш секрета, валидация сессии
- `apps/web/src/middleware.ts` — защита `/admin/**` через cookie `gt_admin_session`
- `apps/web/src/app/admin/login/page.tsx` — форма входа (Server Action)
- `apps/web/src/app/admin/layout.tsx` — шапка с навигацией и кнопкой выхода
- `apps/web/src/app/admin/page.tsx` — редирект на `/admin/audits?status=needs_attention`
- `apps/web/src/app/admin/audits/page.tsx` — список аудитов с фильтром по статусу
- `apps/web/src/app/admin/audits/[auditId]/page.tsx` — детали: метаданные, таймлайн событий, engine runs / артефакты
- `apps/web/src/app/admin/audits/[auditId]/RestartButton.tsx` — client component для перезапуска шага
- `apps/web/src/app/api/admin/audits/[auditId]/restart-step/route.ts` — POST → пишет `admin.step_restart` в `audit_events`

## Auth

- `ADMIN_SECRET` env var
- Cookie `gt_admin_session` = sha256(secret), httpOnly, sameSite=lax, 7 дней
- Middleware перенаправляет неавторизованные запросы к `/admin/**` на `/admin/login?next=<path>`

## Acceptance criteria

- `/admin` редиректит на `needs_attention` по умолчанию ✓
- `/admin/audits` показывает таблицу аудитов с фильтром по всем 10 статусам ✓
- `/admin/audits/:id` открывает детали: метаданные, события, артефакты ✓
- Кнопка "Restart step" пишет `admin.step_restart` событие в `audit_events` ✓
- Неавторизованный запрос → редирект на login ✓
