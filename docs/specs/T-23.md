# T-23 — Teaser Result Page

**Depends on:** T-20 (scoring), T-21 (landing + POST /api/audits)  
**Route:** `/report/[auditId]`  
**Design source:** `Geotrack_UI.zip` → `pages/S4_Result_Page.html`

## What this task delivers

The teaser result page — shown immediately after a free audit completes. The page is publicly accessible via the audit ID in the URL.

## Data requirements

- **Audit** — `id`, `domain`, `url`, `status` from `audits` table
- **Scores** — `scope`, `key`, `score`, `confidenceLow`, `confidenceHigh` from `scores` table
- **Findings** — sorted by `priority` asc from `findings` table
- **Tech checks** — `criterion`, `score`, `details` from `tech_checks` table
- **Engine runs** — first Perplexity run with `responseTextPreview` and joined prompt `text`
- **Mentions** — `brand`, `position`, `sentiment` for the citation engine run

## Page states

| Audit status | What shows |
|---|---|
| `queued`, `running`, `waiting_*` | Processing state (spinner, "Your audit is running…") |
| `completed`, `in_review`, `delivered` | Full teaser result page |
| Not found | Next.js 404 |

## Sections (1:1 with S4_Result_Page.html)

1. **Nav** — sticky, logo + EN/RO language toggle
2. **Breadcrumb** — "Free result" pill active, rest disabled
3. **Score card** — circular gauge (score/10), band label, "Preliminary · N prompts · 1 engine", you-vs-median bar
4. **Email capture** — email input + "Send my link" + Google/Microsoft SSO (UI state only, no backend T-23)
5. **Five pillars** — first 2 visible (Answer Visibility, AI Crawlability); last 3 locked with blur + lock icon + "Unlocked in the full audit"
6. **"What already works" accordion** — collapsed by default, passing `techChecks` items shown on expand
7. **Findings** (3 teaser cards) — severity badge, score delta badge, title, description, evidence block; **no "How to fix", no basket, no "Track"**; "See the fix in the full audit →" link at bottom
8. **Citation block** — header "What {EngineName} said", prompt asked, quoted response with highlighted brands, "Your brand: not mentioned" if absent, other-engines footer
9. **Upgrade card** — left: locked findings rows (blur over REAL data) + total cost; right: Free vs Full table + CTA button
10. **Share section** — OG card preview, Copy link, Share on LinkedIn
11. **Footer** — © 2026 Geotrack · Privacy · Terms
12. **Sticky CTA bar** — fixed bottom, feature count + "Get the full audit — $79"

## Teaser invariants (from CLAUDE.md)

- Finding cards **must not** contain "How to fix", basket, or "Track" controls
- Blur on locked sections applies to **real data from DB**, not placeholder text
- Citation block header uses the **engine's actual name** (e.g., "Perplexity", "ChatGPT", "Gemini")

## Score display

- Overall score: `scope = 'overall', key = 'total'` → rendered as X.X / 10 gauge
- Pillar scores: `scope = 'pillar', key ∈ {A, B, C, D, E}` → bar width = score * 10%
- Category median: `scope = 'category_median', key ∈ {A, B, ...}` → needle position
- Band color thresholds: < 4.0 → `--band-low-*`; 4.0–7.0 → `--band-mid-*`; ≥ 7.0 → `--band-high-*`
