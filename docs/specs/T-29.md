# T-29 — Полный прогон стандартного профиля

## Контекст

Стандартный профиль: 30 промптов (26 категорийных + 4 брендовых), 3 движка (perplexity, chatgpt, gemini), 2 повтора. Итого 180 вызовов адаптеров при холодном кэше. Целевой бюджет шага `engines.poll` из раздела 12.1: **120–180 секунд**.

Concurrency лимиты из `engines.v1.json`:
- Perplexity: 3 параллельных вызова → ceil(60/3) = 20 батчей
- ChatGPT: 5 → ceil(60/5) = 12 батчей
- Gemini: 5 → ceil(60/5) = 12 батчей

Всe три движка опрашиваются параллельно, критический путь — Perplexity (самый медленный при p95-латентности ~5s): 20 × 5s = **100s** ≤ 180s ✓

## Зависимости

T-18 (pollEngines), T-27 (ChatGPT), T-28 (Gemini)

## Scope

1. Harness-тест `apps/worker/src/__tests__/engine-poll-standard-profile.test.ts`:
   - Создаёт 26 категорийных + 4 брендовых промпта (итого 30)
   - Запускает `pollEngines` с 3 адаптерами, 2 повторами, пустым кэшем
   - Проверяет: 180 ответов, 0 partial-движков, все usage-записи заполнены
   - Вычисляет теоретическое время (concurrency math) и утверждает, что оно ≤ 180s
   - Вычисляет статистику токенов (среднее на вызов по каждому движку) и утверждает, что суммарная стоимость ≤ soft ceiling ($6)

2. Файл `fixtures/token-stats-standard-profile.json` — замер токенов по данным из fixtures

## Не входит в scope

- Реальные API-вызовы (тест использует mock-адаптеры с данными из fixtures)
- Шаги пайплайна кроме `engines.poll`

## Acceptance criteria

1. Тест с 30 промптами × 3 движка × 2 повтора возвращает ровно 180 ответов и 0 partial-движков.
2. Теоретическое время шага ≤ 180s при p95-латентности из раздела 12.1.
3. Суммарная расчётная стоимость холодного прогона ≤ $6 (soft ceiling стандартного профиля).
4. `fixtures/token-stats-standard-profile.json` содержит средние токены in/out и оценочную стоимость по каждому движку.
5. `pnpm test` зелёный.
