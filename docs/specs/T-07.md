# T-07 — Адаптеры движков: Gemini Flash и Perplexity

## Scope

- `packages/core/src/adapters/gemini.ts` — `GeminiAdapter implements EngineAdapter`
- `packages/core/src/adapters/perplexity.ts` — `PerplexityAdapter implements EngineAdapter`
- `packages/core/src/adapters/index.ts` — экспорт обоих адаптеров
- `packages/core/src/__tests__/adapters.gemini.test.ts` — контрактный набор тестов
- `packages/core/src/__tests__/adapters.perplexity.test.ts` — контрактный набор тестов
- `fixtures/engines/gemini/ask-basic.json` — записанный ответ Gemini
- `fixtures/engines/perplexity/ask-basic.json` — записанный ответ Perplexity

## Контракт адаптера

Оба адаптера реализуют `EngineAdapter` из `packages/core/src/contracts/engine.ts`:

```ts
interface EngineAdapter {
  id: EngineId;
  ask(prompt: string, opts: AskOptions): Promise<EngineAnswer>;
}
```

`EngineAnswer`:
```ts
{
  text: string;           // текстовый ответ
  sources: { url: string; title?: string }[];  // источники
  raw: unknown;           // сырой ответ API
  usage: UsageRecord;     // стоимость
}
```

## GeminiAdapter

- Endpoint: `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key={apiKey}`
- Модель: `gemini-2.0-flash`
- Инструмент: `{ google_search: {} }` — grounding через Google Search
- Источники извлекаются из `candidates[0].grounding_metadata.grounding_chunks[*].web`
- Стоимость считается через `calcCallCost('gemini', 'gemini-2.0-flash', tokensIn, tokensOut, { groundingCalls: 1 })`
- Принимает `fetch` в опциях конструктора (для тестов)

## PerplexityAdapter

- Endpoint: `POST https://api.perplexity.ai/chat/completions`
- Модель: `sonar`
- Auth: `Authorization: Bearer {apiKey}`
- Источники из `citations: string[]` (массив URL-ов на верхнем уровне ответа)
- Стоимость: `calcCallCost('perplexity', 'sonar', tokensIn, tokensOut, { requestCount: 1 })`
- Принимает `fetch` в опциях конструктора (для тестов)

## Фикстуры

Хранятся в `fixtures/engines/{engine}/ask-basic.json`. Формат — записанный HTTP-ответ тела (JSON).

## Acceptance criteria

- `GeminiAdapter.id === 'gemini'` ✓
- `PerplexityAdapter.id === 'perplexity'` ✓
- `ask()` возвращает `EngineAnswer` с непустым `text` ✓
- `sources` — массив объектов `{ url, title? }` с валидными URL ✓
- `usage.provider` и `usage.model` соответствуют адаптеру ✓
- `usage.costUsd > 0` ✓
- HTTP 4xx/5xx бросает ошибку с кодом статуса ✓
- Сеть не вызывается из тестов (fetch инжектируется) ✓
