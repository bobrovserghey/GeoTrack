# T-14a — Канонические наборы промптов категорий

## Scope

- `packages/config/src/schemas/prompt-set.ts` — Zod-схемы `PromptEntrySchema`, `PromptSetSchema`
- `packages/config/scripts/generate-categories.ts` — генератор наборов
- `packages/config/src/prompts/categories/` — 400 JSON-файлов (200 категорий × 2 локали)
- `packages/config/src/index.ts` — `getPromptSet(categoryId, locale)`, `LOCALES`, `PROMPT_TYPES`
- `packages/config/src/__tests__/prompt-set.test.ts` — тесты
- `packages/config/package.json` — скрипт `prompts:generate-categories`

## Структура файла набора

```json
{
  "categoryId": "project-management-software",
  "locale": "en",
  "version": "1",
  "generatedAt": "2026-09-13",
  "prompts": [
    {
      "id": "discovery-01",
      "text": "best project management software",
      "type": "discovery",
      "priority": 1
    }
  ]
}
```

## Состав 40 промптов (приоритет = порядковый номер)

| Тип | Кол-во | Приоритеты |
|---|---|---|
| discovery | 16 | 1–16 |
| problem-led | 10 | 17–26 |
| comparison | 8 | 27–34 |
| alternative | 4 | 35–38 |
| local | 2 | 39–40 |

Comparison генерируется из топ-5 игроков (topPlayers[0..4]) или меньше если таксономия содержит менее 5.

## Acceptance criteria

- Ровно 400 файлов в `prompts/categories/`
- В каждом файле ровно 40 промптов
- Все `id` уникальны внутри набора
- `priority` от 1 до 40, без дублей
- `type` — только из разрешённого перечня
- `text` непустой
- Zod-схема проходит на каждом файле
- CI зелёный
