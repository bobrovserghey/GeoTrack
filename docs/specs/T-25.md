## API

### POST `/api/audits/[auditId]/email`

Принимает `{ email: string; progressToken: string }`.

1. Валидирует `progressToken` через `report_tokens` (тип `progress`).
2. Нормализует email (trim + lowercase + gmail-normalize).
3. Создаёт или находит запись `users` по `email_normalized`;
   ставит `email_verified = false`, `auth_provider = null`.
4. Обновляет `audits.email_normalized`.
5. Вызывает `supabase.auth.signInWithOtp({email, options: {emailRedirectTo: '/api/auth/callback?next=/report/{auditId}'}})`.
6. Отправляет Inngest-событие `geotrack/audit.email.provided` `{ auditId }`.
7. Ответ `200 { ok: true }`.

### GET `/api/auth/callback`

Query: `?code=<supabase-code>&next=<path>`.

1. Обменивает `code` на сессию через `supabase.auth.exchangeCodeForSession(code)`.
2. Читает `session.user.email`.
3. Обновляет `users`: `email_verified = true`, `verified_at = now()`, `auth_provider` по `session.user.app_metadata.provider`.
4. PostHog: `posthog.capture('email_lead', {distinct_id: email_normalized})`.
5. Редирект на `next` (проверить, что начинается с `/`).

## Изменения воркера

Шаги после `category.preset` / `status.running-after-category`:

```
engine-poll.stub
↓

↓
wait-email                  (waitForEvent 'geotrack/audit.email.provided', match: 'data.auditId', timeout: '7d')

↓

↓
status.completed
```

`brand-prompts.stub`: вставляет события `step.started` / `step.completed` по аналогии с `engine-poll.stub`.

## Компонент EmailGate (S4 дизайн 1:1)

Файл: `apps/web/src/app/report/[auditId]/email-gate.tsx`.  
Пропсы: `{ auditId: string; progressToken: string | null }`.

Состояния:
- По умолчанию: форма с email-полем, кнопкой «Send my link», разделителем «or», кнопками Google и Microsoft.
- После успешного POST: заменить форму на «Check your inbox» (без перезагрузки).
- Кнопки Google/Microsoft: `supabase.auth.signInWithOAuth({provider: 'google'/'azure', options: {redirectTo: '/api/auth/callback?next=/report/{auditId}'}})`.

Email-поле: `type="email"`, `placeholder="you@company.com"`.  
Кнопка «Send my link»: `disabled` при пустом или невалидном email.

Цвета, border-radius, отступы — строго из S4_Result_Page.html строки 636–667.

## Изменения DB

```sql
-- users: новые поля
ALTER TABLE users
  ADD COLUMN email_normalized varchar(254),
  ADD COLUMN email_verified boolean NOT NULL DEFAULT false,
  ADD COLUMN verified_at timestamptz,
  ADD COLUMN auth_provider varchar(32);

CREATE UNIQUE INDEX users_email_normalized_idx ON users (email_normalized)
  WHERE email_normalized IS NOT NULL;

-- audits: email_normalized
ALTER TABLE audits
  ADD COLUMN email_normalized varchar(254);
```
