# T-16. Правила блокеров и скор столпа B

Статус: согласовано
Источник: GEOTRACK_AUDIT_METHODOLOGY_RU.md, столп B; GEOTRACK_TECH_PLAN_MVP_RU.md, разделы 4.5 и 7.3

## Задача

Чистая функция `scorePillarB(facts, config, now)` считает баллы по шести критериям столпа B,
определяет применимые блокеры и возвращает итоговый балл столпа с учётом неизмеренных критериев.

Файл конфигурации `packages/config/src/methodology.v1.json` создаётся в этой задаче.

## Правила скоринга

### Общее правило неизмеренного критерия

Если `facts.bN.measured === false`, критерий исключается из знаменателя:

```
pillarScore = (sum of measured scores) / (sum of measured maxima) * 100
```

### B1 — AI-бот разрешения в robots.txt (max 20)

`accessibleCount` = число ботов с `permission !== 'blocked'`.
`score = round(accessibleCount / 8 * 20)`

### B2 — HTTP-доступность (max 25)

`blockedCount` = число результатов с `blocked === true`.
`totalCount` = `results.length`.
Если `totalCount === 0`: `score = 0`.
`score = round((1 - blockedCount / totalCount) * 25)`

### B3 — Статический контент (max 15)

По `contentRatio`:
- `>= 0.8` → 15
- `>= 0.6` → 12
- `>= 0.4` → 8
- `>= 0.2` → 4
- `< 0.2`  → 0

### B4 — Индексация (max 15)

`indexedCount` = число проиндексированных страниц.
`total` = `pagesChecked.length`.
Если `total === 0`: `score = 0`.
`score = round(indexedCount / total * 15)`

### B5 — Техническая гигиена (max 15)

Четыре компонента:
- Наличие sitemap: 5 баллов если `sitemapPresent`.
- Canonical покрытие: `round(canonicalPresentCount / pageCount * 4)`.
- Нет редиректов среди ключевых страниц: `round(noRedirectCount / pageCount * 3)`.
- TTFB < 800 мс: `round(fastPageCount / pageCount * 3)`.

Если `pageCount === 0` для компонентов кроме sitemap → 0.

### B6 — Свежесть контента (max 10)

Два компонента:
- `sitemapLastmod` (4 балла):
  - `<= 30 дней`: 4; `<= 90 дней`: 3; `<= 180 дней`: 2; `<= 365 дней`: 1; иначе 0.
  - `null` → 0.
- Устаревшие страницы (6 баллов):
  - `total6 = pagesWithLastModified + stalePageCount`
  - Если `total6 === 0` → 6 (нет данных — не штрафуем).
  - `staleRate = stalePageCount / total6`
  - `= 0` → 6; `<= 0.10` → 4; `<= 0.25` → 2; `> 0.25` → 0.

## Правила блокеров

Блокер применяется только если ВСЕ критерии из `dependsOn` измерены.

| id | dependsOn | Условие срабатывания |
|----|-----------|----------------------|
| `b1_all_bots_robots_blocked` | `['b1']` | Все 8 ботов имеют `permission === 'blocked'` |
| `b2_all_bots_http_blocked` | `['b2']` | Для каждого из 8 ботов все его результаты `blocked === true` |
| `b3_no_static_content` | `['b3']` | `contentRatio < 0.2` |
| `b4_no_pages_indexed` | `['b4']` | `pagesChecked.length > 0` и ни одна не проиндексирована |
