# T-28 — Адаптер Gemini с grounding (учёт бесплатной квоты)

## Контекст

Адаптер `GeminiAdapter` реализован в T-07: grounding через `tools: [{ google_search: {} }]`, извлечение источников из `grounding_chunks[].web`, учёт токенов из `usage_metadata`.

Gemini предоставляет **5 000 grounding-вызовов в месяц бесплатно**. На объёмах фазы 1 Gemini Flash — самый дешёвый движок. Необходимо отразить бесплатную квоту в прайс-таблице и в калькуляторе стоимости, чтобы вызывающий код мог корректно вычислять эффективные расходы.

## Зависимости

- T-07 (GeminiAdapter — уже выполнено)

## Scope

1. Добавить `freeGroundingCallsPerMonth: 5000` в запись `gemini/gemini-2.0-flash` в `packages/config/src/provider-prices.v1.json`.
2. Расширить `ModelPriceSchema` (zod) и тип `ModelPrice` полем `freeGroundingCallsPerMonth?: number`.
3. Добавить `freeGroundingCalls?: number` в `CalcOptions` в `packages/core/src/cost/calculator.ts`.
4. Обновить `calcCallCost`: `paidGroundingCalls = max(0, groundingCalls − freeGroundingCalls)` — стоимость считается только с платных вызовов.
5. Добавить тесты в `packages/core/src/__tests__/cost.test.ts` на поведение при наличии и отсутствии бесплатной квоты.

## Не входит в scope

- Трекинг использованной месячной квоты (потребует хранения счётчика в БД / Redis — отдельная задача).
- Адаптер **не знает** сколько квоты потрачено в этом месяце — ответственность вызывающего слоя (worker/engine-poll step). Адаптер по-прежнему передаёт `{ groundingCalls: 1 }` без `freeGroundingCalls`.

## Acceptance criteria

1. `provider-prices.v1.json` содержит `"freeGroundingCallsPerMonth": 5000` для `gemini/gemini-2.0-flash`.
2. `ModelPriceSchema` валидирует это поле (z.number().int().nonnegative().optional()).
3. `calcCallCost('gemini', 'gemini-2.0-flash', 0, 0, { groundingCalls: 1, freeGroundingCalls: 1 })` возвращает `0`.
4. `calcCallCost('gemini', 'gemini-2.0-flash', 0, 0, { groundingCalls: 100, freeGroundingCalls: 40 })` возвращает `≈ 0.84` (60 платных × $0.014).
5. Существующий тест «gemini flash: 100 grounding calls = $1.40» проходит без изменений (нет `freeGroundingCalls` → все вызовы платные).
6. Существующие тесты GeminiAdapter из `adapters.gemini.test.ts` зелёные.
7. `pnpm test` зелёный.
