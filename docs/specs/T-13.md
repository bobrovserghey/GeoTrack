# T-13 — Детекция конкурентов

## Scope

- `packages/core/src/steps/competitor-detect.ts` — Zod-схема `CompetitorDetectOutputSchema`
- `apps/worker/src/steps/competitor-detect.ts` — шаг `detectCompetitors()`
- `fixtures/engines/gemini/competitor-detect.json` — фикстура ответа модели
- `apps/worker/src/__tests__/competitor-detect.test.ts` — тесты шага
- `packages/core/package.json` — экспорт `./steps/competitor-detect`
- `packages/core/src/index.ts` — реэкспорт схемы и типов

## Вход / выход

```ts
// вход
{
  passport:        PassportOutput   // из T-10
  userSuggested?:  string[]         // конкуренты, введённые пользователем (опционально)
  topPlayersHint?: string[]         // ведущие игроки из таксономии (если категория известна)
  maxCount:        number           // из профиля аудита (3 или 5)
}

// выход (CompetitorDetectOutput)
{
  competitors: {
    name:      string   // название конкурента / продукта
    domain?:   string   // домен, если модель может вывести
    rationale: string   // обоснование одной фразой
  }[]   // 0..maxCount; пустой список допустим
}
```

## Поведение шага

- В MVP нет SerpAPI и движков поиска — модель опирается только на своё знание + паспорт
- Контент паспорта изолирован в `<data>` блоке (защита от prompt injection)
- `userSuggested` и `topPlayersHint` передаются в промпт как подсказки, а не как жёсткие ограничения
- Пустой список конкурентов — валидный ответ (`status: 'ok'`, `data.competitors: []`)
- Шаг не ходит в сеть и не запускает поиск

## Три режима отказа

1. Модель не ответила → `status: 'failed'`, note: "Model call failed: …"
2. Ответ не является JSON → `status: 'failed'`, note: "JSON parse failed"
3. Схема не прошла → `status: 'failed'`, note: "Schema validation failed: …"

## Acceptance criteria

- Возвращает `status: 'ok'` и `CompetitorDetectOutput` для валидного паспорта
- `competitors` содержит не более `maxCount` элементов
- Пустой список конкурентов → `status: 'ok'` (не `failed`)
- `<data>` блок присутствует в промпте
- Три режима отказа покрыты тестами
- CI зелёный
