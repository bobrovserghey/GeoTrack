# T-19 — Извлечение упоминаний, позиций, источников

## Цель

Для каждого ответа движка (`EnginePollResponse`) извлечь структурированные факты:
- упомянут ли бренд (`brandMentioned`)
- позиция бренда в списке/ранжировании (`brandListPosition`, `normalizedPositionScore`)
- упомянутые конкуренты с подсчётом вхождений (`competitorMentions`)
- домены источников (`citedDomains`)

Эти факты служат входными данными для скоринга столпа A (T-20):
- A1 (доля упоминаний) — из `brandMentioned`
- A2 (доля цитирований) — из `citedDomains`
- A3 (позиция в списке) — из `normalizedPositionScore`
- A4 (share of voice) — из `competitorMentions`

## Входные данные

```ts
type ExtractMentionsInput = {
  responses: EnginePollResponse[];   // из T-18
  brandName: string;                  // основное название бренда
  brandVariants: string[];            // альтернативные написания
  competitors: string[];              // имена конкурентов
};
```

## Выходные данные

`StepResult<ExtractMentionsOutput>`:

```ts
type EngineResponseFacts = {
  promptId: string;
  engineId: EngineId;
  repeatIndex: number;
  brandMentioned: boolean;
  brandListPosition: number | null;      // 1-based; null если не в списке
  normalizedPositionScore: number | null; // 100 (1-е) .. 20 (5-е и ниже)
  competitorMentions: { name: string; count: number }[];
  citedDomains: string[];               // нормализованные, дедуплицированные домены
};

type ExtractMentionsOutput = {
  facts: EngineResponseFacts[];
};
```

Статус:
- `'ok'` — все извлечения прошли успешно
- `'partial'` — хотя бы одна попытка извлечь позицию через модель упала (`brandListPosition` = null для тех ответов)

## Алгоритм

### Детекция упоминания бренда (детерминировано)
Регулярное выражение с граничным совпадением (`\b...\b`), нечувствительное к регистру. Матчит любой из `brandVariants` или само `brandName`.

### Детекция упоминания конкурентов (детерминировано)
То же регулярное выражение для каждого конкурента. Подсчёт числа вхождений.

### Извлечение позиции в списке (модель)
Вызывается только если `brandMentioned = true`. Малая языковая модель получает текст ответа и список терминов бренда, возвращает 1-based позицию или `null`.

Нормализация позиции:
- позиция 1 → 100
- позиция 2 → 80
- позиция 3 → 60
- позиция 4 → 40
- позиция 5+ → 20

### Извлечение доменов источников (детерминировано)
Список `sources` из `EnginePollResponse` обрабатывается через `normalizeDomain()` (из `@geotrack/core`). Дедуплицируется по домену.

## Eval и метрики

Приёмочные пороги из раздела 5.4 техплана:
- Упоминания бренда (A1): **F-мера ≥ 0,90** на 30 размеченных ответах
- Источники (A2): **Точность извлечения домена ≥ 0,95** на 30 размеченных ответах

Eval запускается скриптом `pnpm test:eval` против золотых наборов в `fixtures/golden/mentions/` и `fixtures/golden/sources/`. Золотые наборы готовит продакт после получения живых ответов (T-18 / T-29).
