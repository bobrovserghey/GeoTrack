# T-15. Технический чек столпа B (критерии B1–B6)

Статус: согласовано
Источник: GEOTRACK_AUDIT_METHODOLOGY_RU.md, столп B; GEOTRACK_TECH_PLAN_MVP_RU.md, Приложение Б

## Задача

Шаг `techCheck` собирает факты для шести критериев столпа B и отдаёт их скорингу. Баллы в этой задаче не считаются.

## Критерии столпа B

| # | Критерий | Описание |
|---|----------|----------|
| B1 | robots.txt | Разрешения для 8 AI-ботов: GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-User, PerplexityBot, Google-Extended, Bingbot |
| B2 | Блокировки на уровне сервера и CDN | HTTP-коды при запросе с user-agent каждого AI-бота к ключевым страницам |
| B3 | Рендеринг без JavaScript | Доля основного контента, доступного в сыром HTML |
| B4 | Индексация в Bing | Проиндексированы ли ключевые страницы; через SerpAPI |
| B5 | Техническая гигиена | sitemap.xml, canonical, статус-коды, TTFB, редиректы |
| B6 | Сигналы свежести | lastmod в sitemap, Last-Modified заголовки, устаревшие страницы |

## Входные данные

```ts
{
  origin: string;          // "https://example.com"
  robotsTxt: string;       // сырой текст robots.txt из снимка краулера
  sitemapUrls: string[];   // URLs из sitemap (из краулера)
  keyPages: string[];      // ключевые страницы (из краулера)
  serpApiKey?: string;     // если undefined → B4 = not measured
  serpApiRequests: number; // из profile.serpApiRequests (2 для тизера, 11 для платного)
}
```

## Выходные данные — `TechCheckFacts`

Каждый критерий Bi возвращает либо структуру фактов, либо признак "не измерен" с причиной.

```ts
type Measured<T> = { measured: true } & T;
type NotMeasured = { measured: false; notMeasuredReason: string };
type CriterionFacts<T> = Measured<T> | NotMeasured;
```

### B1Facts (robots.txt)
- `robotsTxtPresent: boolean`
- `permissions: Record<BotName, BotPermission>` — 'allowed' | 'blocked' | 'not-specified'

### B2Facts (server/CDN blocks)
- `results: Array<{ bot: BotName; url: string; statusCode: number; blocked: boolean }>`
- blocked = true при 403, 429, или статус ≠ 2xx при нормальном UA=200

### B3Facts (JS rendering)
- `url: string` — протестированная страница
- `rawTextLength: number` — длина текста в сыром HTML
- `renderedTextLength: number` — длина текста после рендеринга
- `contentRatio: number` — rawTextLength / renderedTextLength (0–1)

### B4Facts (Bing indexation)
- `pagesChecked: Array<{ url: string; indexed: boolean }>`
- `requestsUsed: number`

### B5Facts (technical hygiene)
- `sitemapPresent: boolean`
- `sitemapUrlCount: number`
- `pageResults: Array<{ url: string; statusCode: number; canonical: string | null; isRedirect: boolean; ttfbMs: number }>`

### B6Facts (freshness)
- `sitemapLastmod: string | null` — самая свежая дата в sitemap
- `pagesWithLastModified: number`
- `stalePageCount: number` — страниц без обновлений >18 месяцев

## Зависимости

- T-08c (краулер: robots.txt и sitemap в снимке)

## Ограничения

- Запросы с user-agent AI-бота (B2): ≤1/сек, остановка при 429
- SerpAPI недоступен → B4: `measured: false, notMeasuredReason: 'SerpAPI unavailable'`
- B3 сравнение по длине текста, **не** HTML
- Баллы в этой задаче не считаются — только сбор фактов
