# T-40: Скоринг столпов D и E + итоговый балл

## Цель

Добавить две функции скоринга:
1. `scorePillarE` — преобразует факты E1–E5 в числовой скор столпа E (0–100) с блокером E1
2. `computeOverallScore` — взвешенная сумма столпов A–E → итоговый балл 0–10 и полоса интерпретации

> **Примечание:** `scorePillarD` уже реализован в T-36 и не меняется в этой задаче.

## Файл 1: `packages/core/src/scoring/pillar-e.ts`

### Тип результата

```ts
export type PillarEResult = {
  criterionScores: Record<'e1' | 'e2' | 'e3' | 'e4' | 'e5', CriterionScore>;
  pillarScore: number;       // 0–100
  measuredMaxSum: number;
  unmeasuredCriteria: string[];
  appliedBlockers: string[]; // 'e1_find_price_failed' если blocker сработал
};
```

### Правила скоринга по критерию

#### E1 — агентные сценарии (maxScore 30)

- `measured: false` если `!e1.measured`
- `successCount` = число сценариев с `success: true` и `attempts > 0`
- `score = round((successCount / 2) * maxScore)` — 2 сценария, каждый стоит maxScore/2

#### E2 — семантика и доступность (maxScore 20)

- `measured: false` если `!e2.measured`
- `totalWeight = critical*4 + serious*2 + moderate*1 + minor*0.5` (суммы per-violation, не per-page)
- `normalizedPenalty = totalWeight / pagesAudited`
- `PENALTY_CAP = 15`
- `score = max(0, round(maxScore * max(0, 1 − normalizedPenalty / PENALTY_CAP)))`

#### E3 — отсутствие барьеров (maxScore 15)

- `measured: false` если `!e3.measured`
- `penalty = captcha*6 + antibot*6 + jsOnly*4 + popup*2`
- `score = max(0, maxScore − penalty)`

#### E4 — машиночитаемые данные (maxScore 20, всегда measured)

- `pricingStructured` → `round(maxScore * 6/20)`; иначе `pricingPageFound` → `round(maxScore * 2/20)`
- `openApiSpecFound` → `round(maxScore * 5/20)`
- `apiDocsFound` → `round(maxScore * 5/20)`
- `productCatalogFound` → `round(maxScore * 4/20)`

#### E5 — интерфейсы агентов (maxScore 15, всегда measured)

- `llmsTxtValid` → `round(maxScore * 5/15)`; иначе `llmsTxtFound` → `round(maxScore * 2/15)`
- `agentsJsonFound` → `round(maxScore * 4/15)`
- `webMcpManifestFound` → `round(maxScore * 3/15)`
- `mcpServerFound` → `round(maxScore * 3/15)`

### Blocker E1

Условие: `e1.measured === true && e1.findPrice.attempts > 0 && !e1.findPrice.success`
Эффект: `pillarScore = min(pillarScore, 40)`, в `appliedBlockers` добавляется `'e1_find_price_failed'`

### pillarScore

- `measuredScoreSum / measuredMaxSum * 100` (округлённый), 0 если measuredMaxSum=0

## Файл 2: `packages/core/src/scoring/overall.ts`

```ts
export type OverallScoreResult = {
  pillarScores: Record<'A' | 'B' | 'C' | 'D' | 'E', number>;
  weightedSum: number;    // 0–100, округлённый
  overallScore: number;   // 0–10.0, 1 знак после запятой
  band: string;           // из methodology.v1.json bands
};
```

Формула:
```
weightedSum = round(wA*A + wB*B + wC*C + wD*D + wE*E)
overallScore = round(weightedSum) / 10
band = bands.find(b => weightedSum >= b.min && weightedSum <= b.max)?.label ?? 'unknown'
```

## Тесты

### `scoring-e.test.ts`
- E1: 2/2 → maxScore; 1/2 → maxScore/2; 0/2 (ran) → 0; not measured → 0
- E1 blocker: find_price failed (attempts>0) → pillarScore capped at 40
- E2: 0 violations → maxScore; penalty=15 → 0; not measured → 0
- E3: no barriers → maxScore; all barriers → 0; not measured → 0
- E4: all signals → maxScore; nothing → 0
- E5: all → maxScore; nothing → 0
- pillarScore: measuredMaxSum=0 → pillarScore=0

### `scoring-overall.test.ts`
- All pillars 100 → overallScore 10.0, band 'excellent'
- All pillars 0 → overallScore 0.0, band 'critical'
- Mixed → correct weighted sum and band
- Band boundaries: 50 → 'poor', 51 → 'fair', 86 → 'excellent'
