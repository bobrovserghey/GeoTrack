## Нормализация домена

```ts
normalizeDomain(input: string): string
```

- Принимает URL (`https://www.example.com/path`) или домен (`www.example.com`)
- Возвращает нижний регистр, без протокола/пути/порта, без обёрточных поддоменов
- Обёрточные поддомены: `www`, `www2`, `m`, `mobile`
- Примеры: `"https://WWW.Acme.com/pricing"` → `"acme.com"`, `"m.shop.io"` → `"shop.io"`

## Контракт ModelAdapter

```ts
interface ModelAdapter {
  generate(prompt: string, opts?: GenerateOptions): Promise<ModelAnswer>;
}
type GenerateOptions = { timeoutMs?: number; jsonMode?: boolean };
type ModelAnswer   = { text: string; usage: UsageRecord };
```

Отличие от `EngineAdapter`: модель не выдаёт источники, используется для структурированного извлечения, **без grounding**.

## GeminiModelAdapter

- Вызывает `POST /v1beta/models/{model}:generateContent` без поля `tools`
- При `jsonMode: true` добавляет `generationConfig: { response_mime_type: "application/json" }`
- Инъектируемый `fetch` для тестов
- Учёт стоимости через `calcCallCost('gemini', model, tokensIn, tokensOut, {})`

## Шаг `productPassport`

```ts
type PageSnapshot = { url: string; textContent: string };

productPassport(
  input: { pages: PageSnapshot[] },
  model: ModelAdapter,
): Promise<StepResult<PassportOutput>>
```

**Алгоритм:**
1. Берём до 5 страниц (`pages.slice(0, 5)`)
2. Для каждой берём до 4 000 символов `textContent`
3. Собираем промпт с явным блоком `<data>` (п. 9.3 техплана — недоверенный текст отделён от инструкций)
4. Вызываем `model.generate(prompt, { jsonMode: true, timeoutMs: 30_000 })`
5. Парсим JSON → `PassportOutputSchema.parse()`
6. При ошибке парсинга → `status: 'failed'`, `data: null`

**Промпт-инвариант:** недоверенный текст сайта передаётся в отдельном `<data>` блоке с пометкой, что это данные, а не инструкции.

## Acceptance criteria

- `normalizeDomain` корректен на 10+ случаях (URL, домен, поддомен-обёртка, FQDN с точкой, регистр)
- `GeminiModelAdapter.generate()` вызывает Gemini без `tools`, с `response_mime_type` при `jsonMode`
- `productPassport` возвращает `status: 'ok'` и валидный `PassportOutput` на эталонной фикстуре
- `productPassport` возвращает `status: 'failed'` при невалидном JSON от модели
- Все тесты без сетевых вызовов (fetch и resolver инжектируются)
- CI зелёный, TypeScript чистый
