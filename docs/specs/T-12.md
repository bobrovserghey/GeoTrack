# T-12 — Детекция категории

## Scope

- `packages/core/src/steps/category-detect.ts` — Zod-схема `CategoryDetectOutputSchema`
- `apps/worker/src/steps/category-detect.ts` — шаг `detectCategory()`
- `fixtures/engines/gemini/category-detect.json` — фикстура ответа модели
- `apps/worker/src/__tests__/category-detect.test.ts` — тесты шага
- `packages/core/package.json` — экспорт `./steps/category-detect`
- `packages/core/src/index.ts` — реэкспорт схемы и типа

## Вход / выход

```ts
// вход
{
  passport: PassportOutput           // из T-10
  taxonomy: CategoryEntry[]          // из T-11 (все 200)
}

// выход (CategoryDetectOutput)
{
  categoryId:  string           // id из таксономии, выбранная категория
  confidence:  number           // 0..1
  rationale:   string           // обоснование одной фразой
  candidates:  { categoryId: string; confidence: number }[]  // топ-3 кандидата
  autoSelected: boolean         // true, если выбрано по таймауту без участия пользователя
}
```

## Поведение шага

- Модель получает паспорт и компактный список категорий (id + name, 200 строк)
- Возвращает JSON: `{ category_id, confidence, rationale, candidates[] }`
- Шаг парсит JSON, валидирует по схеме, возвращает `StepResult<CategoryDetectOutput>`
- Поле `autoSelected` в выводе шага всегда `false`; значение `true` выставляет оркестратор при автовыборе по таймауту (10 минут, T-22)
- Категория-подсказка из паспорта (`categoryHint`) передаётся в промпт как hint, не как жёсткое ограничение

## Три режима отказа

1. Модель не ответила → `status: 'failed'`, note: "Model call failed: …"
2. Ответ не является JSON → `status: 'failed'`, note: "JSON parse failed"
3. Схема не прошла → `status: 'failed'`, note: "Schema validation failed: …"

## Acceptance criteria

- Возвращает `status: 'ok'` и корректный `CategoryDetectOutput` для валидного паспорта
- `categoryId` присутствует в переданном списке taxonomy
- `confidence` в диапазоне 0..1
- `candidates` содержит 1–3 элемента, включает выбранную категорию
- `autoSelected` всегда `false` на выходе шага (оркестратор выставляет при таймауте)
- Корректно возвращает `failed` при ошибке модели, сломанном JSON и несоответствии схеме
- `<data>` блок изолирует контент паспорта от инструкций промпта
- CI зелёный
