# T-04 — Cost tracking + provider price tables + budget enforcement

## Scope

- `packages/config/src/provider-prices.v1.json` — price table for all providers/models
- `packages/config/src/schemas/provider-prices.ts` — Zod schema + types
- `packages/config/src/index.ts` — `getProviderPrices()` exported
- `packages/core/src/cost/calculator.ts` — `calcCallCost(provider, model, tokensIn, tokensOut, options?)`
- `packages/core/src/cost/budget.ts` — `createBudget(profile)`, `checkBudget(budget)`, `recordUsage(budget, record)`
- `packages/core/src/cost/index.ts` — barrel
- `packages/core/src/index.ts` — re-exports cost module

## Budget status mapping (handled by orchestrator, not budget module)

| Profile type | `hard_exceeded` → audit status |
|---|---|
| teaser | `failed` |
| standard / extended | `needs_attention` |

## Acceptance criteria

- `calcCallCost` returns correct USD for known token/request counts ✓
- soft ceiling fires at exactly the soft ceiling value ✓
- hard ceiling fires at exactly the hard ceiling value ✓
- teaser hard ceiling → `hard_exceeded` (orchestrator maps to `failed`) ✓
- standard hard ceiling → `hard_exceeded` (orchestrator maps to `needs_attention`) ✓
