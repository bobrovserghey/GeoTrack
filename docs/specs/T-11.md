# T-11 — Таксономия категорий (200 записей)

## Scope

- `packages/config/src/schemas/taxonomy.ts` — Zod-схема `CategoryEntrySchema`, `TaxonomySchema`
- `packages/config/src/taxonomy.v1.json` — 200 категорий с ведущими игроками
- `packages/config/src/index.ts` — экспорт `getTaxonomy()`, `getCategoryById()`
- `packages/config/src/__tests__/taxonomy.test.ts` — тесты уникальности и полноты

## Структура записи

```ts
{
  id:         string,  // kebab-case, уникальный, e.g. "project-management-software"
  name:       string,  // человекочитаемое название, e.g. "Project Management Software"
  topPlayers: string[] // 3–10 ведущих игроков категории для сравнительных промптов
}
```

`topPlayers` берётся из таксономии, а не с сайта клиента (требование техплана раздел 7.3).

## Acceptance criteria

- Ровно 200 записей в файле
- Все `id` уникальны
- `id` соответствует формату kebab-case (`/^[a-z0-9]+(?:-[a-z0-9]+)*$/`)
- `name` непустой, ≤ 120 символов
- `topPlayers` содержит от 3 до 10 элементов, все непустые
- Zod-схема проходит на полном файле без ошибок
- CI зелёный
