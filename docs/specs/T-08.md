# T-08 — safe-fetch, Playwright-фабрика, краулер

## T-08a: `core/net/safe-fetch`

**Файлы:**
- `packages/core/src/net/ip-check.ts` — `isBlockedIp()` (все приватные диапазоны IPv4 + IPv6)
- `packages/core/src/net/safe-fetch.ts` — `safeFetch`, `createSafeFetch`, `SafeFetchError`
- `packages/core/src/__tests__/ip-check.test.ts` — 16 тестов
- `packages/core/src/__tests__/safe-fetch.test.ts` — 14 тестов

**Защита (раздел 9.2):**
- Резолв всех адресов хоста → блокировка при любом приватном IPv4/IPv6
- IPv4-mapped IPv6 (`::ffff:192.168.x.x`) — блокируется
- Адрес метаданных `169.254.169.254` — блокируется
- Ручная обработка редиректов: максимум 5, проверка IP на каждом
- Только схемы `http:`/`https:`, порты 80/443
- Тело ≤ 2 МБ (настраиваемо через `maxBodyBytes`)
- Пауза между запросами к домену (`domainPauseMs`, по умолчанию 1 с)
- Закрепление IP через undici Agent (`lookup` override)
- Сеть из тестов не используется: `resolver` и `fetch` инжектируются

## T-08b: Playwright-фабрика

**Файлы:**
- `apps/worker/src/browser/browser-guard.ts` — `shouldBlockRequest()` (чистая функция)
- `apps/worker/src/browser/playwright-factory.ts` — `createAuditContext()`
- `apps/worker/src/__tests__/browser-guard.test.ts` — 18 тестов

**Блокировка в route-перехвате:**
- Схемы кроме `http:`/`https:` → abort
- IP-литерал в хосте (IPv4 `x.x.x.x` и IPv6 `::`) → abort
- Порты кроме 80 и 443 → abort
- Типы ресурсов `media`, `font`, `websocket` → abort
- Хост резолвится через `isBlockedIp` с кэшем per-audit
