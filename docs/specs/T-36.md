# T-36 — Столп D: offsite-signals шаг (D1, D2, D4)

## Статус

В разработке

## Зависимости

- T-13 (competitor-detect — CompetitorDetectOutput)
- T-32 (source-map — SourceMapOutput)
- T-34 (cited-pages — CitedPagesOutput)

## Зачем

Шаг `collectOffsiteSignals` собирает сигналы внешнего следа бренда:
- **D1 — Площадки отзывов**: есть ли профиль клиента на G2, Capterra, Product Hunt, Trustpilot
- **D2 — Присутствие в источниках цитирования**: как часто бренд упоминается на страницах, которые LLM цитировала по промптам категории (из CitedPagesOutput T-34)
- **D4 — Консистентность сущности**: найдены ли страницы LinkedIn компании и Crunchbase-профиль

D1 и D4 собираются через SerpAPI (Google-поиск). D2 вычисляется из `CitedPagesOutput` — без дополнительных сетевых вызовов.

Недоступность SerpAPI помечает D1 и D4 `measured: false` — они не влияют на столп (исключаются из знаменателя). D2 не требует SerpAPI.

Тизерный профиль не включает столп D (`pillars` не содержит `"D"`); шаг не вызывается.

## SerpAPI-запросы

Каждый запрос — поиск Google через `https://serpapi.com/search.json?engine=google&num=3`.

| Критерий | Запросы | Всего |
|---|---|---|
| D1 | `"{entityName}" site:g2.com`, `site:capterra.com`, `site:producthunt.com`, `site:trustpilot.com` | 4 |
| D4 | `"{entityName}" linkedin company`, `"{entityName}" crunchbase` | 2 |
| **Итого** | | **6** |

## Вход → выход: D1

Для каждой из 4 платформ:
1. Отправить запрос `"{entityName}" site:{platform-domain}` в SerpAPI Google.
2. Если `organic_results[0]` существует и его `link` содержит доменное имя платформы → `profileFound: true`, `profileUrl: link`.
3. Иначе → `profileFound: false`, `profileUrl: null`.

Если SerpAPI вернул ≠200 или выбросил ошибку при первом запросе → остановить D1, вернуть `measured: false`.

```ts
export type ReviewPlatformFact = {
  platform: 'g2' | 'capterra' | 'producthunt' | 'trustpilot';
  profileFound: boolean;
  profileUrl: string | null;
};

export type D1ReviewFacts = {
  measured: boolean;
  clientPlatforms: ReviewPlatformFact[];   // пустой если measured = false
  clientPlatformCount: number;             // 0 если measured = false
};
```

Платформы и их домены:
- `g2` → `g2.com`
- `capterra` → `capterra.com`
- `producthunt` → `producthunt.com`
- `trustpilot` → `trustpilot.com`

## Вход → выход: D2

Вычисляется из `citedPages: CitedPagesOutput` — без сетевых вызовов.

```ts
export type D2CitationFacts = {
  measured: boolean;                // false если citedPages.analyzedPageCount === 0
  citedPagesAnalyzed: number;
  pagesWithClientMention: number;
  clientPresenceRatio: number;      // pagesWithClientMention / analyzedPageCount, или 0
};
```

## Вход → выход: D4

Для каждого из 2 запросов:
1. Поиск `"{entityName}" linkedin company` → проверить, есть ли в `organic_results[0].link` подстрока `linkedin.com/company`.
2. Поиск `"{entityName}" crunchbase` → проверить `crunchbase.com/organization` или `crunchbase.com/company`.

Если SerpAPI вернул ≠200 → `measured: false`.

```ts
export type D4EntityFacts = {
  measured: boolean;
  linkedInFound: boolean;
  linkedInUrl: string | null;
  crunchbaseFound: boolean;
  crunchbaseUrl: string | null;
};
```

## Скоринг столпа D

Функция `scorePillarD(offsite: OffsiteSignalsOutput, config: Methodology): PillarDResult`.

### D1 — абсолютная шкала (нет данных по конкурентам в MVP)

| clientPlatformCount | score |
|---|---|
| ≥ 4 | maxScore |
| 3 | Math.round(maxScore * 0.75) |
| 2 | Math.round(maxScore * 0.50) |
| 1 | Math.round(maxScore * 0.25) |
| 0 | 0 |

`measured: d1.measured`

### D2 — прямо пропорционально

`score = Math.round(d2.clientPresenceRatio * maxScore)`

`measured: d2.measured`

### D4 — по числу найденных источников

| foundCount | score |
|---|---|
| 2 | maxScore |
| 1 | Math.round(maxScore * 0.5) |
| 0 | 0 |

`measured: d4.measured`

### Итоговый скор

```ts
export type PillarDResult = {
  criterionScores: Record<'d1' | 'd2' | 'd4', CriterionScore>;
  pillarScore: number;
  measuredMaxSum: number;
  unmeasuredCriteria: string[];
};
```

`pillarScore = measuredMaxSum === 0 ? 0 : Math.round(measuredScoreSum / measuredMaxSum * 100)`

## Тесты worker (offsite-signals)

1. **D1 все 4 найдены** — SerpAPI возвращает результат с ссылкой для каждой платформы → `clientPlatformCount = 4`.
2. **D1 частично найдены** — 2 платформы вернули результаты, 2 пустых → `clientPlatformCount = 2`.
3. **D1 none found** — все SerpAPI вернули `organic_results: []` → `clientPlatformCount = 0`.
4. **D1 ключ отсутствует** — `serpApiKey: undefined` → `d1.measured = false`.
5. **D1 SerpAPI вернул 429** → `d1.measured = false`, `serpRequestsUsed` равен числу сделанных запросов до ошибки.
6. **D2 measured** — `citedPages.analyzedPageCount = 10`, `pagesWithClientMentionCount = 3` → `clientPresenceRatio = 0.3`.
7. **D2 unmeasured** — `citedPages.analyzedPageCount = 0` → `d2.measured = false`, `clientPresenceRatio = 0`.
8. **D4 оба найдены** — первый результат содержит `linkedin.com/company`, второй `crunchbase.com` → `linkedInFound = true, crunchbaseFound = true`.
9. **D4 только LinkedIn** — crunchbase-результат отсутствует → `crunchbaseFound = false`.
10. **D4 ни одного** — оба результата пустые → `linkedInFound = false, crunchbaseFound = false`.
11. **D4 SerpAPI 503** → `d4.measured = false`.
12. **serpRequestsUsed** — посчитать сумму фактически отправленных запросов.
13. **D1 ошибка на второй платформе** — первая платформа ответила, вторая бросила ошибку → `d1.measured = false`, сделанные до ошибки запросы считаются.

## Тесты скоринга (scoring-d)

1. **D1 maxScore** — clientPlatformCount = 4 → maxScore.
2. **D1 1 платформа** → Math.round(maxScore * 0.25).
3. **D1 unmeasured** → measured = false, в unmeasuredCriteria.
4. **D2 ratio 0.6** → Math.round(0.6 * maxScore).
5. **D2 ratio 0** → score = 0.
6. **D2 unmeasured** → measured = false.
7. **D4 2 найдено** → maxScore.
8. **D4 1 найдено** → Math.round(maxScore * 0.5).
9. **D4 0** → score = 0.
10. **D4 unmeasured** → measured = false.
11. **pillarScore всё measured** → корректная нормировка.
12. **pillarScore все unmeasured** → pillarScore = 0.

Тесты worker и scoring зелёные; typecheck и eslint чистые.
