# T-24 — Карточка «поделиться» (OG-изображение)

## Scope

- `apps/web/src/app/report/[auditId]/opengraph-image.tsx` — новый файл Next.js App Router OG-маршрута

## Зависимости

T-23 (результаты аудита в DB)

## Описание

Генерирует PNG 1200×630 px — 1:1 с дизайном `S5_Share_Image.html` — через `next/og` (satori).

Маршрут публичный: прогресс-токен не требуется.  
При отсутствии `DATABASE_URL` рендерится с демо-данными.

## Структура карточки

```
┌─────────────────────────────────────────────┐
│ [logo]                          acme.com     │  top
├─────────────────────────────────────────────┤
│  4.2         │  vs category median 4.6       │
│  ▲ Rarely    │  Answer Visibility  2.8 ████  │  middle
│    mentioned │  AI Crawlability    6.1 ██    │
│              │  ...                          │
├─────────────────────────────────────────────┤
│ Geotrack AI visibility audit   Sep 12, 2026 │  bottom
└─────────────────────────────────────────────┘
```

## Цвета (без переменных — satori не поддерживает)

| Элемент       | Hex       |
|---------------|-----------|
| Фон           | `#020617` |
| slate-400     | `#94A3B8` |
| low band      | `#DB4E1D` |
| mid band      | `#F0A213` |
| high band     | `#3A7055` |

## Пороги оценки

- `< 4` → low (orange-600)  "Rarely mentioned"
- `4–7` → mid (amber-500)   "Sometimes mentioned"
- `≥ 7` → high (green-600)  "Frequently mentioned"

## Шрифты

Inter 600 и JetBrains Mono 700 — загружаются с Google Fonts при генерации.

## Изменения API / DB

Нет. Только чтение: `audits.domain`, `audits.createdAt`, `scores`.
Ключи: `overall:total` / `total:score`, `pillar:{A-E}`, `category_median:total`.
